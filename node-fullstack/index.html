你的快速通道

如果你已学过 C / Java / Python 的变量、循环、函数、基本 OOP——前 7 章不用逐字读。每章开头已标注"📌 有编程基础？"的跳读建议，指出哪些是 JS 特有的、哪些可跳。

建议节奏：第 1–7 章用 3–5 天速览（重点看隐式转换、==/===、map/filter/reduce），从 第 8 章作用域与闭包 开始进入正题。
