日夜模式：代码

CSS 变量 + classList.toggle 的经典方案

核心思路：CSS 变量 + body 类名切换。JS 只需要一行 classList.toggle，剩下的全是 CSS 的事。

/* style.css — 用 CSS 变量定义主题 */
:root {
    --bg-color: #ffffff;
    --text-color: #333333;
    --transition-speed: 0.3s;
}
body.dark-theme {
    --bg-color: #121212;
    --text-color: #e0e0e0;
}
body {
    background-color: var(--bg-color);
    color: var(--text-color);
    transition: background-color var(--transition-speed) ease,
                color var(--transition-speed) ease;
}
// script.js — 切换逻辑
const themeBtn = document.querySelector('#theme-toggle');
const icon = themeBtn.querySelector('span');

themeBtn.addEventListener('click', () => {
    document.body.classList.toggle('dark-theme');
    icon.textContent = document.body.classList.contains('dark-theme')
        ? '🌙' : '☀️';
});
常见问题：切换后某些元素没变色。检查那些元素是不是用了硬编码颜色（如 color: #333）而不是 var(--xxx)。只有用 CSS 变量声明的属性才会随主题变化。

打字机标题

逐字打出 → 停顿 → 逐字删除 → 循环切换

日夜模式搞定了——你已经掌握了选元素、监听事件、改 DOM 内容的基本功。接下来用同样的 DOM 基础，做一个更复杂的效果。

你一定见过这样的个人网站：页面加载后，标题一个字一个字地蹦出来，打完一句话停顿一下，然后一个字一个字地消失，换下一句。这种效果叫打字机动画，让访客觉得"这个网站是活的"。

要实现的效果：Hero 区域主标题逐字打出"你好，我是[你的名字]"。停顿 1.5 秒后逐字删除，再打出"一名前端开发爱好者"。无限循环。

思路拆解：

  • 准备一个字符串数组，存储多句预设文案
  • 用 setTimeout 递归控制节奏——不是 setInterval，因为打出和删除的速度不同
  • 打完 → 停顿 → 逐字删除 → 切换到下一句
  • slice(0, i) 截取前 i 个字符，更新 textContent

打字机：代码

setTimeout 递归 + 字符串截取

const titles = [
    "你好，我是张三",
    "一名前端开发爱好者",
    "热爱开源与创造"
];
const el = document.querySelector('#hero-title');
let titleIdx = 0, charIdx = 0, isDeleting = false;

function typeWriter() {
    const current = titles[titleIdx];

    if (!isDeleting) {
        // 逐字打出
        el.textContent = current.slice(0, charIdx + 1);
        charIdx++;
        if (charIdx === current.length) {
            isDeleting = true;      // 打完了，准备删除
            setTimeout(typeWriter, 1500); // 停顿 1.5 秒
            return;
        }
        setTimeout(typeWriter, 120);  // 打字速度：每字 120ms
    } else {
        // 逐字删除
        el.textContent = current.slice(0, charIdx - 1);
        charIdx--;
        if (charIdx === 0) {
            isDeleting = false;     // 删完了，换下一句
            titleIdx = (titleIdx + 1) % titles.length;
            setTimeout(typeWriter, 400);   // 短暂停顿后开始下一句
            return;
        }
        setTimeout(typeWriter, 60);  // 删除比打出快一倍
    }
}

typeWriter(); // 启动！

几个值得注意的细节：

  • 打字速度 120ms，删除速度 60ms——删除比打出快，这是打字机效果的"手感"秘诀
  • 用 isDeleting 标志位区分"打"和"删"两个阶段
  • (titleIdx + 1) % titles.length 让数组循环

项目卡片类

用 class 封装"项目卡片"的数据与渲染逻辑

先设计好数据结构，再写请求。这样拿到数据后直接传给构造函数就行，不用到处拼字符串。

class ProjectCard {
    constructor(repo) {
        this.name = repo.name;
        this.description = repo.description || '暂无描述';
        this.url = repo.html_url;
        this.language = repo.language || '未知';
        this.stars = repo.stargazers_count;
    }

    render() {
        const card = document.createElement('div');
        card.className = 'project-card';
        card.setAttribute('data-language', this.language);
        card.innerHTML = `
            <h3>
                <a href="${this.url}" target="_blank">${this.name}</a>
            </h3>
            <p>${this.description}</p>
            <span class="lang-tag">${this.language}</span>
            <span class="stars">⭐ ${this.stars}</span>
        `;
        return card;
    }
}

每个仓库对应一个 new ProjectCard(repo) 实例，调用 .render() 就拿到一个完整的 DOM 节点。数据存在属性里，渲染逻辑封装在方法里——这就是 OOP 的核心思想。后面的筛选功能也会用到 data-language 属性。

获取仓库数据

用 fetch + async/await 拉取 GitHub API

ProjectCard 类设计好了，现在去拿数据。注意 data-language 属性——下一步的筛选系统会用到它。

async function loadProjects() {
    const container = document.querySelector('#projects-list');
    const username = '你的GitHub用户名';

    try {
        const response = await fetch(
            `https://api.github.com/users/${username}/repos`
        );

        if (!response.ok) {
            throw new Error(`HTTP ${response.status}`);
        }

        const repos = await response.json();

        repos.forEach(repo => {
            const card = new ProjectCard(repo);
            container.appendChild(card.render());
        });

    } catch (error) {
        container.innerHTML = '<p>加载项目失败，请稍后再试 🥲</p>';
        console.error('获取仓库数据失败:', error);
    }
}

loadProjects();
常见问题：请求返回 403。GitHub API 对未认证请求有速率限制（每小时 60 次）。频繁测试被限流时，在请求头加 Token： 
const response = await fetch(url, {
    headers: { 'Authorization': 'token 你的Token' }
});
到 GitHub Settings → Developer settings → Personal access tokens 生成。Token 不要提交到公开仓库！

动态生成按钮 + 事件委托 + CSS 过渡动画

function createFilterButtons(repos) {
    const languages = [...new Set(repos.map(r => r.language).filter(Boolean))];
    const bar = document.querySelector('#filter-bar');

    // "全部"按钮
    bar.innerHTML = '<button class="filter-btn active" data-lang="all">全部</button>';

    // 每种语言一个按钮
    languages.forEach(lang => {
        bar.innerHTML += `<button class="filter-btn" data-lang="${lang}">${lang}</button>`;
    });

    // 事件委托：在 bar 上统一监听，不用给每个按钮绑定
    bar.addEventListener('click', (e) => {
        if (!e.target.classList.contains('filter-btn')) return;

        bar.querySelectorAll('.filter-btn')
            .forEach(b => b.classList.remove('active'));
        e.target.classList.add('active');

        const lang = e.target.dataset.lang;
        document.querySelectorAll('.project-card').forEach(card => {
            const match = lang === 'all' || card.dataset.language === lang;
            card.classList.toggle('hidden', !match);
        });
    });
}
/* CSS 配合过渡动画 */
.project-card {
    transition: opacity 0.4s ease, transform 0.4s ease;
}
.project-card.hidden {
    opacity: 0;
    transform: scale(0.95);
    pointer-events: none;
    position: absolute;
}
常见问题：隐藏的卡片仍然占位。只设 opacity: 0 的元素依然占据空间。加上 position: absolute 让它脱离文档流。要动画用 absolute，要简洁用 display: none（但没过渡动画）。

const observer = new IntersectionObserver((entries) => {
    entries.forEach(entry => {
        if (entry.isIntersecting) {
            entry.target.classList.add('animate-in');
            observer.unobserve(entry.target); // 只触发一次！
        }
    });
}, { threshold: 0.5 });

document.querySelectorAll('.skill-bar')
    .forEach(bar => observer.observe(bar));

threshold: 0.5 = 元素有 50% 进入视口才触发。unobserve 确保只触发一次，不会来回滚动时反复播放。

轻量级博客

用 Marked.js 解析 Markdown，实现无后端博客系统

你有一堆 Markdown 格式的笔记或文章，但每次展示给别人都要单独开仓库或用第三方平台。能不能直接在自己的主页上做一个博客？用 fetch 加载本地 .md 文件，用 Marked.js 解析成 HTML，就是一个完整的无后端博客。

要实现的效果：

  • 主页"我的博客"区域只显示博文标题列表
  • 标题从 posts 文件夹动态读取（post1.md, post2.md ...）
  • 点击标题：页面不跳转，在当前页动态获取并解析 Markdown
  • 将格式化后的 HTML 渲染到阅读区域
async function loadPost(filename) {
    try {
        const res = await fetch(`posts/${filename}`);
        const md = await res.text();
        document.getElementById('post-content').innerHTML =
            marked.parse(md); // Marked.js 解析
    } catch (err) {
        console.error('加载文章失败:', err);
    }
}
常见问题：fetch 本地文件返回 404。GitHub Pages 的路径是大小写敏感的，posts/Post1.md 和 posts/post1.md 是两个不同的文件。另外 posts 文件夹必须和 index.html 同层，并且文件已 push 到仓库。

粒子星空背景

用 Canvas 实现星空粒子 + 鼠标引力效果

前面的选修让网站"有内容"，接下来的彩蛋让网站"有灵魂"。这些小功能不需要大而全，但要有质感——给访客一个"哇"的瞬间。至少选做 1 项。

你见过那些背景是星空的网站吗？鼠标一滑，星星被"吸"过去，松开又散回来。这种效果用 <canvas> + requestAnimationFrame 就能实现。关键是理解动画循环：每帧清空画布 → 更新粒子位置 → 重新绘制。

要实现的效果：

  • 整个页面背景为 <canvas> 画布
  • 画布上随机分布闪烁的"星星"粒子
  • 鼠标移动时，周围产生更密集的"星云"
  • 附近星星受引力影响，产生穿梭感

图：粒子星空背景效果

【AI 生图提示词】请生成一张粒子星空背景效果示意图： - 画面主体：深色（#0a0a2e 深蓝黑）背景上散布大量微小的白色和淡蓝色圆点，模拟星空 - 画面中央偏右有一个鼠标光标图标，周围 150px 范围内的粒子被"吸引"聚集，形成密集的星云效果 - 远离光标的粒子保持随机分布，大小不一（1px-3px），部分粒子带微弱的光晕效果 - 光标吸引区域用虚线圆圈标注"引力范围 150px" - 右下角放一个小标签" + requestAnimationFrame" - 配色建议：#0a0a2e 深蓝黑背景，粒子白色/淡蓝色，鼠标区域有微弱的蓝白渐变光晕 - 画面比例：16:9 - 避免：过度装饰、UI 元素、文字说明区域过多 

/* 核心动画循环 */
function animate() {
    ctx.clearRect(0, 0, canvas.width, canvas.height);

    particles.forEach(p => {
        const dx = mouse.x - p.x;
        const dy = mouse.y - p.y;
        const dist = Math.sqrt(dx * dx + dy * dy);

        if (dist < 150) {
            p.x += dx * 0.01; // 被鼠标吸引
            p.y += dy * 0.01;
        }

        ctx.beginPath();
        ctx.arc(p.x, p.y, p.size, 0, Math.PI * 2);
        ctx.fillStyle = p.color;
        ctx.fill();
    });

    requestAnimationFrame(animate);
}

练习知识点：Canvas API、坐标计算、requestAnimationFrame

隐藏彩蛋

↑↑↓↓←→←→BA —— 输入秘籍触发惊喜

Konami Code 是游戏史上最有名的秘籍。你的网站上也可以藏一个：页面上没有任何提示，只有"知道的人"才能触发。这个功能的精髓在于用数组模拟滑动窗口——只保留最近的 N 次按键，和秘钥序列做比较。

const konamiCode = [
    'ArrowUp', 'ArrowUp', 'ArrowDown', 'ArrowDown',
    'ArrowLeft', 'ArrowRight', 'ArrowLeft', 'ArrowRight',
    'KeyB', 'KeyA'
];
let inputBuffer = [];

window.addEventListener('keydown', (e) => {
    inputBuffer.push(e.code);

    // 滑动窗口：只保留最近 10 次按键
    if (inputBuffer.length > konamiCode.length) {
        inputBuffer.shift();
    }

    // 比较是否匹配
    if (inputBuffer.join(',') === konamiCode.join(',')) {
        triggerEasterEgg();
        inputBuffer = [];
    }
});

function triggerEasterEgg() {
    document.body.classList.toggle('retro-theme');
    // 或者弹出一个贪吃蛇小游戏...
}

练习知识点：keydown 事件、event.code、数组 push + shift 滑动窗口
