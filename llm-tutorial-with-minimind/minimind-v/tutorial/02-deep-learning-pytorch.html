Part 1：什么是深度学习

从生物神经元到人工神经元，理解神经网络如何学习。

深度学习的"深"指的是网络层数多，"学习"指的是通过数据自动调整参数。本节先用一个简单的神经元模型建立直觉，再看整个网络是如何通过"预测→纠错→调整"的循环来学习的。

  • 从生物到人工 —— 神经元的数学抽象与代码实现
  • 学习过程 —— 前向传播、损失、反向传播、参数更新的循环

从生物神经元到人工神经元

生物神经元接收信号（树突）、处理信号（细胞体）、输出信号（轴突）。人工神经元用数学模拟了这个过程：输入 → 加权求和 → 激活函数 → 输出。

图：生物神经元与人工神经元的对比

【AI 生图提示词】请生成一张中文技术示意图，风格简洁、配色柔和、适合教学： - 画面主体：左右对比图，左侧为生物神经元结构，右侧为人工神经元结构 - 左侧元素关系：树突（接收信号）→ 细胞体（处理信号）→ 轴突（输出信号），用箭头依次连接 - 右侧元素关系：输入 x₁, x₂, x₃ → 加权求和 Σ(wᵢ × xᵢ) + b → 激活函数 f(加权和) → 输出 y，用箭头依次连接 - 关键标注：左侧标注"生物神经元"，右侧标注"人工神经元"；左右对应元素用虚线连接（树突↔输入，细胞体↔加权求和+激活，轴突↔输出） - 配色建议：浅灰背景，左侧用绿色系，右侧用蓝色系，箭头用深灰色 - 画面比例：16:9 - 避免：过度装饰、3D 效果、杂乱的颜色 

# 一个"人工神经元"
def neuron(x, w, b):
    weighted_sum = sum(wi * xi for wi, xi in zip(w, x)) + b  # 加权求和
    return sigmoid(weighted_sum)  # 激活函数

# 例子
x = [0.5, 0.3, 0.8]  # 输入（3个信号）
w = [0.2, -0.1, 0.4] # 权重（3个连接强度）
b = 0.1               # 偏置
output = neuron(x, w, b)

深度学习就是把很多这样的神经元连在一起，形成"深层"网络。层数越多，能学到的模式越复杂。MiniMind-V 的 Transformer 就是由成百上千个这样的神经元组成的 8 层网络。

神经网络如何学习

神经网络的学习过程是一个反复"预测→纠错→调整"的循环。每一步都让模型离正确答案更近一点。

图：神经网络训练的完整循环流程

【AI 生图提示词】请生成一张中文技术示意图，风格简洁、配色柔和、适合教学： - 画面主体：一个环形循环流程图，展示神经网络训练的五个步骤 - 各元素关系：① 准备训练数据（输入 + 正确答案）→ ② 前向传播（模型做出预测）→ ③ 计算损失（预测 vs 正确答案的差距）→ ④ 反向传播（计算每个参数该怎么调）→ ⑤ 参数更新（微调所有权重）→ 判断"损失够小了吗？"，若否则回到①，若是则训练完成 - 关键标注：每个步骤用圆角矩形表示，判断节点用菱形表示；判断节点标注"否→继续训练"和"是→训练完成" - 配色建议：浅灰背景，步骤节点用浅蓝色，判断节点用橙色，完成节点用绿色 - 画面比例：16:9 - 避免：过度装饰、3D 效果、杂乱的颜色

就像学开车：踩油门（前向传播）→ 发现偏了（计算损失）→ 调方向盘（反向传播）→ 重复直到开直

这个循环中的每一步都有对应的 PyTorch 代码：output = model(data) 是前向传播，loss = F.cross_entropy(output, target) 是计算损失，loss.backward() 是反向传播，optimizer.step() 是参数更新。

Part 2: 基本组件

线性层、激活函数、损失函数、优化器——搭建神经网络的四大积木。

理解这四个组件，你就能看懂任何神经网络的训练代码。每个组件在 MiniMind-V 中都有对应的实现。

  • 线性层（nn.Linear） —— 最基本的神经网络层，本质是矩阵乘法
  • 激活函数 —— 引入非线性，让多层网络有意义
  • 损失函数 —— 衡量预测与正确答案的差距
  • 优化器 —— 决定如何根据梯度更新参数

线性层（nn.Linear）

线性层是最基本的神经网络层，做一件事：矩阵乘法。公式是 y = xW^T + b，其中 W 是权重矩阵，b 是偏置。它将输入从一个维度映射到另一个维度。

# PyTorch 中的线性层
import torch.nn as nn

linear = nn.Linear(in_features=3, out_features=2)
# 本质: y = xW^T + b
# 输入: 3 维 → 输出: 2 维

图：线性层输入与输出的全连接关系

【AI 生图提示词】请生成一张中文技术示意图，风格简洁、配色柔和、适合教学： - 画面主体：左右两列神经元的全连接图 - 左列：输入层 3 个神经元，分别标注 x₁、x₂、x₃ - 右列：输出层 2 个神经元，分别标注 y₁ = w₁₁x₁ + w₁₂x₂ + w₁₃x₃ + b₁ 和 y₂ = w₂₁x₁ + w₂₂x₂ + w₂₃x₃ + b₂ - 连线：每个输入神经元与每个输出神经元之间都有连线，共 6 条，表示全连接 - 配色建议：浅灰背景，输入节点用蓝色，输出节点用绿色，连线用灰色 - 画面比例：16:9 - 避免：过度装饰、3D 效果、杂乱的颜色

在 MiniMind-V 中：model_minimind.py 使用了大量线性层：

self.q_proj = nn.Linear(768, 768, bias=False)  # Query 投影
self.k_proj = nn.Linear(768, 384, bias=False)  # Key 投影
self.v_proj = nn.Linear(768, 384, bias=False)  # Value 投影

注意 Key 和 Value 的输出维度是 384（768 的一半），这是因为 MiniMind-V 使用了分组查询注意力（GQA），多个 Query 头共享同一组 Key/Value。

常见困惑：为什么 K/V 是 384 不是 768？

别误以为是写错了。MiniMind-V 的 Q 有 8 个头（8×96=768），但 K/V 只有 4 个头（4×96=384）。这就是 GQA——每 2 个 Q 头共用一组 K/V。等到第 4 章讲 Attention 时你会再遇到它，那里会解释这么做的内存好处。

激活函数

没有激活函数，多层线性网络等价于一层——不管你叠多少层 y = Wx + b，最终都可以合并成一层。激活函数引入非线性，让网络能学到复杂的模式。

import torch
import torch.nn.functional as F

# ReLU: 最简单，负数变0，正数不变
x = torch.tensor([-2.0, -1.0, 0.0, 1.0, 2.0])
print(F.relu(x))        # [0.0, 0.0, 0.0, 1.0, 2.0]

# SiLU (Swish): sigmoid(x) * x — MiniMind-V 使用这个
print(F.silu(x))         # [-0.238, -0.269, 0.0, 0.731, 1.762]

# GELU: 近似于 SiLU，常用于 Transformer
print(F.gelu(x))         # [-0.036, -0.159, 0.0, 0.841, 1.954]

没有激活函数？

3 层线性 = 1 层线性，不管加多少层都无法学到非线性模式。这就是"深度"没有意义。

有激活函数

每一层都有非线性变换，网络可以逼近任意复杂的函数。层数越多，表达能力越强。

在 MiniMind-V 中：model_minimind.py 第143行使用 SiLU 激活函数用于 FFN 层，model_vlm.py 第29行投影层使用 GELU 激活函数。两者都是平滑的激活函数，比传统的 ReLU 更适合 Transformer 架构。

损失函数：交叉熵损失

损失函数衡量模型预测与正确答案之间的差距。语言模型最常用的是交叉熵损失（Cross-Entropy Loss）——它的直觉很简单：模型对正确答案越确信，损失越小；越不确定，损失越大。

图：交叉熵损失的计算过程

【AI 生图提示词】请生成一张中文技术示意图，风格简洁、配色柔和、适合教学： - 画面主体：从左到右的流程图，展示交叉熵损失的计算步骤 - 各元素关系：模型输出 Logits（如 [2.1, -0.5, 0.3, ...] 共 6400 个数）→ Softmax（转为概率分布）→ 正确答案位置的概率 P = 0.65 → Loss = -log(0.65) = 0.431 - 关键标注：Logits 旁标注"原始打分"；Softmax 旁标注"转为概率"；P 旁标注"正确答案的概率"；Loss 旁标注"越小越好" - 配色建议：浅灰背景，步骤用蓝色方框，Logits 用橙色，Loss 用红色强调 - 画面比例：16:9 - 避免：过度装饰、3D 效果、杂乱的颜色 

import torch
import torch.nn.functional as F

# 模型对 5 个词的原始打分
logits = torch.tensor([[2.1, -0.5, 0.3, 0.1, -1.0]])
# 正确答案是第 0 个词
target = torch.tensor([0])

# 计算交叉熵损失
loss = F.cross_entropy(logits, target)
print(f"Loss: {loss.item():.4f}")

# 手动计算验证
probs = F.softmax(logits, dim=-1)
print(f"概率: {probs}")
print(f"-log(P[正确答案]): {-torch.log(probs[0, 0]):.4f}")
# 两者应该相等！

在 MiniMind-V 中：model_minimind.py 使用 F.cross_entropy(x.view(-1, x.size(-1)), y.view(-1), ignore_index=-100)，其中 ignore_index=-100 表示标签为 -100 的位置不计算损失（这些位置是 Padding 或不需要预测的位置）。

优化器：梯度下降

优化器决定如何根据梯度更新参数。MiniMind-V 使用 AdamW 优化器——它在传统 SGD 的基础上增加了自适应学习率和权重衰减，收敛更快更稳定。

图：梯度下降寻找损失最低点的过程

【AI 生图提示词】请生成一张中文技术示意图，风格简洁、配色柔和、适合教学： - 画面主体：一个起伏的损失地形（类似山谷的等高线图或3D曲面），上面有一个小球从高处向低处滚动的轨迹 - 各元素关系：参数空间 → 损失地形（高低起伏）→ 梯度 = 最陡上坡方向 → 沿梯度反方向走一步 w = w - lr × 梯度 → 逐渐走到最低点（损失最小） - 关键标注：起点标注"初始参数"，终点标注"最优参数（损失最小）"，箭头标注"学习率 lr 控制步长" - 配色建议：浅灰背景，等高线用蓝色渐变，小球轨迹用红色，最低点用绿色标记 - 画面比例：16:9 - 避免：过度装饰、杂乱的颜色 

import torch
import torch.nn as nn
import torch.optim as optim

# 创建简单模型和优化器
model = nn.Linear(10, 2)
optimizer = optim.AdamW(model.parameters(), lr=0.001)

# 训练步骤（这是每个训练循环的核心）
for data, target in dataloader:
    optimizer.zero_grad()          # 1. 清零旧梯度
    output = model(data)           # 2. 前向传播
    loss = F.cross_entropy(output, target)  # 3. 计算损失
    loss.backward()                # 4. 反向传播（计算梯度）
    optimizer.step()               # 5. 更新参数

上面代码中的五个步骤是所有 PyTorch 训练的固定模式，MiniMind-V 的训练代码完全遵循这个模式。AdamW 相比普通 SGD 的优势：它为每个参数自动调整学习率（自适应），并添加权重衰减来防止过拟合。

Part 3: 传播机制

理解数据在神经网络中的流动方式，以及梯度是如何回传的。

前向传播是数据从输入流向输出的过程，反向传播是梯度从输出回传到输入的过程。两者方向相反，共同构成了神经网络"学习"的核心机制。

  • 前向传播 —— 数据从输入到输出的流动过程，维度如何变化
  • 反向传播 —— 用链式法则从输出向输入逐层计算梯度
  • 完整训练循环 —— 将五步合为一体的训练流程

前向传播：数据在模型中的流动

前向传播是数据从输入到输出的流动过程。以 MiniMind-V 为例，一段文本经过嵌入层、8 个 Transformer Block、归一化层、最终线性层，输出每个位置上 6400 个词的概率分布。

注意维度的变化规律：嵌入层将整数 ID 转为 768 维向量，Transformer Block 保持维度不变（[seq_len, 768] → [seq_len, 768]），最后的 lm_head 将 768 维映射到 6400 维（词表大小）。

反向传播：梯度的回传

反向传播就是用链式法则从输出向输入逐层计算梯度。梯度告诉每个参数"你应该往哪个方向调整、调整多少"。

图：反向传播中梯度的回传路径

【AI 生图提示词】请生成一张中文技术示意图，风格简洁、配色柔和、适合教学： - 画面主体：从右到左的流程图（与前向传播方向相反），展示梯度如何从损失函数逐层回传 - 各元素关系：Loss = -log(p) → ∂L/∂logits → lm_head 的梯度 → ∂L/∂hidden → Block 8 的梯度 → Block 7 的梯度 → ... → Block 1 的梯度 → 嵌入层的梯度 - 关键标注：每个节点标注"∂L/∂某参数"的形式，箭头从右向左，表示梯度回传方向 - 配色建议：浅灰背景，梯度回传箭头用红色（与前向传播蓝色形成对比），Loss 节点用橙色强调 - 画面比例：16:9 - 避免：过度装饰、3D 效果、杂乱的颜色

反向传播的关键设计：残差连接让梯度可以"跳过"某些层直接传到前面，这是训练深层网络的关键技术。没有残差连接，梯度在逐层回传时会逐渐消失（梯度消失问题），导致前面的层几乎无法学习。MiniMind-V 的每个 Transformer Block 都包含残差连接。

# 最小反向传播示例
w = torch.tensor([1.0], requires_grad=True)   # 要学习的参数
loss = (w - 3) ** 2                            # 目标：让 w 趋近 3
loss.backward()                                # 反向传播，自动算出梯度

print(w.grad)   # tensor([-4.])  ← 梯度告诉 w 该往哪个方向调
# 梯度为负 → 说明 w 应该增大；PyTorch 的 autograd 引擎替你算好了这一步

Part 4 PyTorch

Tensor、nn.Module、autograd、DataLoader——PyTorch 的四大基石。

掌握了这四个核心概念，你就能读懂 MiniMind-V 的全部代码。每个概念在项目中都有大量使用场景。

  • Tensor 张量 —— PyTorch 的基本数据结构，多维数组
  • nn.Module —— 所有网络层的基类
  • autograd —— 自动求导引擎
  • DataLoader —— 批量数据加载工具
  • GPU 与 CUDA —— 加速训练的硬件支持

Tensor（张量）

nn.Module

PyTorch 中所有网络层的基类。定义网络就是两步：__init__ 定义层（搭建结构），forward 定义计算流程（数据如何流动）。MiniMind-V 的每个组件（RMSNorm、Attention、FFN 等）都是一个 nn.Module。

    def forward(self, x):

autograd 自动求导

PyTorch 的 autograd 引擎会自动追踪所有张量运算，在调用 loss.backward() 时自动计算所有参数的梯度。你不需要手动推导和编写求导公式——PyTorch 帮你搞定。

import torch

# 创建需要梯度的张量
x = torch.tensor([1.0, 2.0, 3.0], requires_grad=True)

# 前向计算
y = x.sum()           # y = 1 + 2 + 3 = 6
y.backward()           # 反向传播

print(x.grad)          # tensor([1., 1., 1.])  ← 每个元素的梯度都是 1
# 因为 dy/dx_i = 1（sum 的梯度）

autograd 的工作原理：PyTorch 在前向传播时自动构建"计算图"——记录每个运算的输入和输出。调用 backward() 时，它沿计算图反向遍历，用链式法则计算每个参数的梯度。这就是为什么你只需要定义前向传播，PyTorch 就能自动算出梯度。

GPU 加速与混合精度训练

GPU 的并行计算能力比 CPU 快 10-100 倍，是训练神经网络的必备硬件。混合精度训练通过将计算从 32 位浮点数降到 16 位，将显存占用减半、计算速度翻倍，同时精度几乎不变。

input_ids = input_ids.to(device)

报错排查：bfloat16 在我的显卡上不支持？

症状：运行时报 "CUDA error: no kernel image is available for execution" 或 "astype" 相关错误。

原因：bfloat16 需要 NVIDIA Ampere 架构及以上（A100、RTX 30 系、40 系）。GTX 10 系（如 1080、2080）不支持。

修复：老显卡把 dtype=torch.bfloat16 改成 dtype=torch.float16，或直接去掉 autocast 用纯 float32（慢但能跑）。

混合精度训练的工作原理：前向传播用 BFloat16（快速省显存），梯度更新仍用 Float32（保持精度）。PyTorch 的 GradScaler 负责在两种精度之间自动转换，你只需要用 with autocast() 包裹前向传播代码。

Part 5: 训练技巧

让训练更稳定、更高效的实用技巧。这些技巧在 MiniMind-V 的训练代码中都有使用。

训练神经网络不只是"跑循环"那么简单。学习率太大训练会发散，太小训练会太慢；梯度太大会导致参数飞出合理范围，显存不够会导致无法训练。这三个技巧分别解决这三个问题。

  • 余弦退火 —— 学习率按余弦曲线逐渐降低，先快后慢
  • 梯度裁剪 —— 防止梯度爆炸导致训练崩溃
  • 梯度累积 —— 显存不够时用时间换空间

余弦退火学习率调度

MiniMind-V 使用余弦退火（Cosine Annealing）策略。训练开始时学习率最大，让模型快速学到大致的模式；随着训练进行，学习率按余弦曲线平滑降低，让模型在最优解附近做精细调整。

# trainer_utils.py
def get_lr(current_step, total_steps, lr):
    return lr * (0.1 + 0.45 * (1 + math.cos(math.pi * current_step / total_steps)))

# 学习率变化轨迹（假设 lr=5e-6, total=10000）:
# Step    0: lr ≈ 5.0e-6  （最大值，快速学习）
# Step 2500: lr ≈ 4.34e-6
# Step 5000: lr ≈ 2.75e-6 （中间值）
# Step 7500: lr ≈ 1.16e-6
# Step 10000: lr ≈ 0.5e-6  （最小值，精细调整）

最终学习率是初始学习率的 1/10（lr * 0.1），不会降到 0。这确保模型在训练末期仍能做微小的调整。公式中的余弦函数 cos() 保证了学习率的下降是平滑的，不会突然大幅变化。

梯度裁剪与梯度累积

梯度裁剪：防止梯度爆炸

当梯度的值变得非常大时，参数更新幅度过大，导致训练不稳定甚至崩溃（Loss 突然变成 NaN）。梯度裁剪通过限制梯度的最大范数来防止这个问题。

# 防止梯度爆炸（梯度值太大导致训练不稳定）
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
# 如果梯度的范数 > 1.0，就按比例缩小到 1.0

梯度累积：显存不够的替代方案

当显存不够增大 batch_size 时，可以用小 batch 多次前向传播，累积梯度后再更新。效果等同于使用更大的 batch_size。

练习 1：线性回归

目标：用 PyTorch 学习 y = 3x + 1 这个线性关系。模型从随机参数开始，通过训练自动发现权重 w ≈ 3.0 和偏置 b ≈ 1.0。

import torch
import torch.nn as nn

# 生成数据: y = 3x + 1 + 噪声
x = torch.randn(100, 1)
y = 3 * x + 1 + 0.5 * torch.randn(100, 1)

# 创建模型：一个线性层 y = wx + b
model = nn.Linear(1, 1)
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)

# 训练循环（注意这五步是固定模式）
for epoch in range(100):
    optimizer.zero_grad()              # 1. 清零梯度（必须在前向传播之前）
    pred = model(x)                    # 2. 前向传播
    loss = ((pred - y) ** 2).mean()    # 3. 计算损失（均方误差）
    loss.backward()                    # 4. 反向传播
    optimizer.step()                   # 5. 更新参数

    if epoch % 20 == 0:
        print(f"Epoch {epoch}: loss={loss.item():.4f}, "
              f"w={model.weight.item():.4f}, b={model.bias.item():.4f}")
# 最终: w ≈ 3.0, b ≈ 1.0 ✅

关键观察：(1) 训练前 w 和 b 是随机值；(2) 随着训练进行，loss 逐步降低，w 趋近 3.0，b 趋近 1.0；(3) 训练循环的五步模式与前面的介绍完全一致。

练习 2：MNIST

目标：搭建一个两层全连接网络，识别 28×28 的手写数字图片（0-9）。这个练习综合运用了 nn.Module、DataLoader、交叉熵损失和 Adam 优化器。

import torch
import torch.nn as nn
from torchvision import datasets, transforms

# 加载数据
train_data = datasets.MNIST('./data', train=True, download=True,
                            transform=transforms.ToTensor())
loader = torch.utils.data.DataLoader(train_data, batch_size=64, shuffle=True)

# 定义网络：两层全连接
class SimpleNet(nn.Module):         # 继承 nn.Module
    def __init__(self):
        super().__init__()          # 调用父类
        self.fc1 = nn.Linear(28*28, 128)  # 输入 784 → 隐藏 128
        self.fc2 = nn.Linear(128, 10)     # 隐藏 128 → 输出 10（0-9数字）

    def forward(self, x):
        x = x.view(-1, 28*28)       # 展平 28×28 图片为 784 维向量
        x = torch.relu(self.fc1(x))  # 第一层 + ReLU 激活
        x = self.fc2(x)              # 第二层（输出 logits）
        return x

model = SimpleNet()
optimizer = torch.optim.Adam(model.parameters(), lr=0.001)

for epoch in range(5):
    for images, labels in loader:
        output = model(images)                          # 前向传播
        loss = nn.functional.cross_entropy(output, labels)  # 交叉熵损失
        optimizer.zero_grad()                           # 清零梯度
        loss.backward()                                 # 反向传播
        optimizer.step()                                # 更新参数
    print(f"Epoch {epoch}: loss={loss.item():.4f}")

关键对比：这个练习用到了本阶段学到的几乎所有概念——nn.Module 定义网络、DataLoader 加载数据、cross_entropy 计算损失、Adam 优化器、ReLU 激活函数、forward 定义前向传播。如果你能看懂这段代码，说明你已经准备好了进入第三阶段（NLP 基础）。
