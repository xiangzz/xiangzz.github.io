MiniMind-V 学习路线

从零开始理解视觉语言模型

关于本教程

本教程专为零基础新手设计。MiniMind-V 是一个极简的视觉语言模型（VLM），核心代码不到 500 行 Python——你可以把它当作理解 GPT-4V、Gemini 等大型多模态模型的"最小可运行标本"。

跟随本路线循序渐进，你将经历十个阶段，从 Python 变量开始，一步步走到能自己训练一个能看图说话的 AI。每个阶段都以前一阶段为基础，不存在"突然跳到看不懂"的情况。

本教程的核心学习路径是：编程基础 → 深度学习框架 → Transformer 架构 → 阅读源码 → 动手训练。其中 Transformer 架构（阶段 4）是全路线最关键的理解瓶颈——突破它之后，VLM 只是在 LLM 基础上"加两个零件"。

Part 4：项目架构速览

了解 MiniMind-V 的代码目录结构和各文件职责，在后续阅读源码时你可以快速定位。

MiniMind-V 的代码组织非常简洁。核心只有三个目录：model/ 存放模型定义，dataset/ 存放数据加载逻辑，trainer/ 存放训练脚本。整个项目的可读代码量不到 1000 行。

核心概念：一句话总结

图片就是一门"外语"，视觉编码器就是"翻译词典"，把图片翻译成语言模型能理解的"语言"。

MiniMind-V 的数据流可以用一行代码概括：

图片(256×256) → SigLIP2(冻结) → 64个视觉token → MLP投影层 → 插入文本中 → LLM处理 → 输出回答

视觉编码阶段

  • 输入图片尺寸：256 × 256
  • SigLIP2 视觉编码器（冻结不训练，直接使用预训练权重）
  • 输出 64 个视觉 token，每个 token 是一个向量

语言生成阶段

  • MLP 投影层将视觉 token 映射到与文本 token 相同的向量空间
  • 视觉 token 替换文本中的 <|image_pad|> 占位符
  • LLM 统一处理文本和视觉 token，生成回答

先不用记住每个术语的细节。随着学习的深入，你会逐一理解 SigLIP2（阶段 6）、投影层（阶段 6）、Token 替换（阶段 7）和 LLM（阶段 4-5）的内部原理。
