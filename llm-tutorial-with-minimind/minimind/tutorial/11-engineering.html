6 个训练器（pretrain / sft / lora / dpo / grpo / ppo）各自实现一遍吗？

参数统计

定义：get_model_params() 区分 MoE 模型的"总参数"和"活跃参数"。

白话：MoE 模型像个大公司——员工很多（总参数），但每次只派一小撮人干活（活跃参数）。

代码——来自 trainer_utils.py：

def get_model_params(model, config):
    total = sum(p.numel() for p in model.parameters()) / 1e6
    n_routed = config.n_routed_experts    # 总专家数
    n_active = config.num_experts_per_tok  # 每次激活几个
    expert = sum(p.numel() for n, p in model.named_parameters()
                 if 'mlp.experts.0.' in n) / 1e6
    shared_expert = sum(p.numel() for n, p in model.named_parameters()
                        if 'mlp.shared_experts.0.' in n) / 1e6
    base = total - (expert * n_routed) - (shared_expert * n_shared)
    active = base + (expert * n_active) + (shared_expert * n_shared)
    if active < total:
        Logger(f'Model Params: {total:.2f}M-A{active:.2f}M')
    else:
        Logger(f'Model Params: {total:.2f}M')
Model Params: 198.42M-A63.91M

余弦学习率

定义：get_lr() 实现余弦退火调度，让学习率在训练过程中平滑变化。

白话：起步时学习率较低（0.1倍），保证训练稳定；中段学习率最高（约0.55倍），是学习最积极的阶段；末段学习率再次降低，精细收敛不冲过头。

代码：

def get_lr(current_step, total_steps, lr):
    return lr * (0.1 + 0.45 * (1 + math.cos(
        math.pi * current_step / total_steps)))

lr 调度详解

训练阶段cos 值lr 倍率效果
开始 (step=0)cos(0) = 10.1 x lr较低学习率（warmup 效果）
中间 (step=N/2)cos(pi/2) = 00.55 x lr中等学习率
结束 (step=N)cos(pi) = -10.1 x lr回到低学习率（精细调整）

为什么开始和结束都是低学习率？

开始时参数是随机的，大步更新容易"震飞"；结束时参数接近最优，小步微调才能精细收敛。

随机种子

定义：setup_seed() 统一设置所有随机源，保证每次运行结果可复现。

白话：深度学习的每一步都有随机性（数据打乱、Dropout、采样）。固定种子就是"抽签前先洗好牌"，保证下次抽到一样的。

代码：

def setup_seed(seed: int):
    random.seed(seed)               # Python 内置随机
    np.random.seed(seed)            # NumPy 随机
    torch.manual_seed(seed)         # PyTorch CPU 随机
    torch.cuda.manual_seed(seed)    # 当前 GPU 随机
    torch.cuda.manual_seed_all(seed)  # 所有 GPU 随机
    torch.backends.cudnn.deterministic = True   # cuDNN 确定性
    torch.backends.cudnn.benchmark = False       # 关闭自动调优

主进程日志

定义：Logger() 确保在多 GPU 训练时，日志只在主进程打印一次。

白话：4 张 GPU 跑同样的代码，不加判断的话，一条日志打印 4 遍，终端就炸了。

代码：

def is_main_process():
    return not dist.is_initialized() or dist.get_rank() == 0

def Logger(content):
    if is_main_process():   # 只在 rank=0 的主 GPU 上打印
        print(content)

如果不加判断会怎样？ 4 张 GPU 各打印一次，同一条日志出现 4 遍，终端一片混乱。

定义：SkipBatchSampler 在断点续训时跳过已经处理过的 batch，避免数据重复。

class SkipBatchSampler(Sampler):
    def __init__(self, sampler, batch_size, skip_batches=0):
        self.sampler = sampler
        self.batch_size = batch_size
        self.skip_batches = skip_batches

    def __iter__(self):
        batch, skipped = [], 0
        for idx in self.sampler:
            batch.append(idx)
            if len(batch) == self.batch_size:
                if skipped < self.skip_batches:
                    skipped += 1
                    batch = []
                    continue      # 跳过已处理的 batch！
                yield batch
                batch = []

    def __len__(self):
        total = (len(self.sampler) + self.batch_size - 1) // self.batch_size
        return max(0, total - self.skip_batches)

class LMForRewardModel:
    def __init__(self, model_path, device="cuda", dtype=torch.float16):
        self.tokenizer = AutoTokenizer.from_pretrained(
            model_path, trust_remote_code=True)
        self.model = AutoModel.from_pretrained(
            model_path, torch_dtype=dtype, trust_remote_code=True)
        self.model = self.model.to(device).eval()

    @torch.no_grad()
    def get_score(self, messages, response):
        # 把对话历史和新问题拼成评估输入
        history_text = "\n".join(
            [f"{m['role']}: {m['content']}" for m in messages[:-1]])
        last_query = messages[-1]['content'] if messages else ""
        eval_messages = [
            {"role": "user", "content": f"{history_text}\n{last_query}"},
            {"role": "assistant", "content": response}
        ]
        score = self.model.get_score(self.tokenizer, eval_messages)
        return max(min(score, 3.0), -3.0)  # 裁剪到 [-3, 3]

定义：init_model() 是所有训练器创建模型的统一入口。

白话：不管哪个训练器，"造模型"这一步都调它。参数决定了是随机初始化还是加载已有权重。

def init_model(lm_config, from_weight='pretrain',
               tokenizer_path='../model', save_dir='../out', device='cuda'):
    tokenizer = AutoTokenizer.from_pretrained(tokenizer_path)
    model = MiniMindForCausalLM(lm_config)

    if from_weight != 'none':
        # 加载已有权重（微调 / 继续训练）
        moe_suffix = '_moe' if lm_config.use_moe else ''
        weight_path = f'{save_dir}/{from_weight}_{lm_config.hidden_size}{moe_suffix}.pth'
        weights = torch.load(weight_path, map_location=device)
        model.load_state_dict(weights, strict=False)
    # from_weight == 'none' 时不加载，随机初始化（从头训练）

    get_model_params(model, lm_config)
    Logger(f'Trainable Params: '
           f'{sum(p.numel() for p in model.parameters() if p.requires_grad) / 1e6:.3f}M')
    return model.to(device), tokenizer

DDP 初始化流程

定义：分布式数据并行（DDP）让多个 GPU 同时训练，每个 GPU 处理不同数据，然后同步梯度。

白话：一个人搬砖慢，找 4 个人同时搬。每个人搬自己的那份，搬完对一下账（同步梯度），保证每个人拿到的结果一样。

代码：

def init_distributed_mode():
    if int(os.environ.get("RANK", -1)) == -1:
        return 0  # 单卡模式，不初始化 DDP

    dist.init_process_group(backend="nccl")  # 用 NVIDIA 的 NCCL 通信
    local_rank = int(os.environ["LOCAL_RANK"])
    torch.cuda.set_device(local_rank)  # 绑定当前进程的 GPU
    return local_rank

DDP 关键概念

NCCL

NVIDIA 的 GPU 间通信库，专门为 GPU 集合通信优化，速度非常快。

All-Reduce

把所有 GPU 的梯度加起来再平均，确保每张卡拿到相同的梯度后独立更新参数。

主进程 rank=0

负责保存模型、打印日志。只有 rank=0 的进程执行这些操作，避免重复。

DistributedSampler

确保每个 GPU 看到不同的数据分片，不会重复处理同一条样本。
