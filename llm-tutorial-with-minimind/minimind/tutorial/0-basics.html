继承与 self

三步理解面向对象：定义蓝图 → 创建对象 → 调用方法

class Attention(nn.Module):          # ① 继承 nn.Module
    def __init__(self, dim):          # ② 构造函数：买积木
        super().__init__()            # 调用父类构造（必须）
        self.q_proj = nn.Linear(dim, dim, bias=False)  # 用 self 存储层

    def forward(self, x):             # ③ 前向计算：搭积木
        return self.q_proj(x)         # self = "我自己"

# 使用：创建对象 → 调方法
attn = Attention(dim=768)             # 触发 __init__
out = attn.forward(x)                 # 触发 forward
  • 继承：class Child(Parent)，子类获得父类全部能力
  • self：对象自身的引用，类似日常说的"我的"
  • super().__init__()：先让父类完成初始化

装饰器与生成器

# ---- 装饰器：给函数"穿外套"，不改动原代码 ----
@torch.no_grad()          # 推理时不计算梯度，节省显存

    ...

@abstractmethod           # 强制子类必须实现此方法

    pass
# ---- 生成器 yield：一次只吐一行，不把文件全读进内存 ----
def get_training_texts(path):
    with open(path, 'r') as f:
        for line in f:
            yield line.strip()   # 暂停，把这一行交给调用方

for text in get_training_texts("data.txt"):
    tokens = tokenizer(text)     # 逐行处理，内存友好

Python 常见陷阱

可变默认参数：def f(x, lst=[]) 的 lst 只创建一次，多次调用共享。修复：def f(x, lst=None): lst = lst or []
整数除法 vs 浮点除法：3 / 2 = 1.5（浮点），3 // 2 = 1（整除）。MiniMind 中维度计算常用 //，如 dim // n_heads。
浅拷贝：b = a 只是让 b 指向 a。修改 b 会改 a。修复：用 b = a.copy() 或 import copy; b = copy.deepcopy(a)。

训练循环五步

MiniMind 中 train_pretrain.py 的核心——记住这五步就够了

# ① 前向传播：输入数据，得到预测和损失
res = model(input_ids, labels=labels)
loss = res.loss

# ② 反向传播：计算每个参数的梯度
scaler.scale(loss).backward()

# ③ 梯度裁剪：防止梯度爆炸
scaler.unscale_(optimizer)

# ⑤ 梯度清零：为下一步准备
optimizer.zero_grad(set_to_none=True)

nn.Module

定义：神经网络层的基类 | 白话：所有层都是它的子类 | 用法：__init__ 买积木，forward 搭积木

class Attention(nn.Module):
    def __init__(self, dim):
        super().__init__()
        # __init__：定义需要哪些层（买积木）
        self.q_proj = nn.Linear(dim, dim, bias=False)
        self.k_proj = nn.Linear(dim, dim // 2, bias=False)
        self.v_proj = nn.Linear(dim, dim // 2, bias=False)
        self.out_proj = nn.Linear(dim, dim, bias=False)

    def forward(self, x, mask=None):
        # forward：定义计算流程（搭积木）
        q = self.q_proj(x)          # (B, seq, dim)
        k = self.k_proj(x)          # (B, seq, dim//2)
        v = self.v_proj(x)
        # ... 注意力计算（阶段 2 详解）
        return self.out_proj(attn_output)

关键特性：在 __init__ 中赋值给 self 的 nn.Module 会被自动追踪。model.parameters() 能递归收集所有参数。

比喻卸甲：上面"买积木/搭积木"只是为了建立直观感受。在 PyTorch 内部，nn.Module 实际上是通过一个 _modules 字典注册子层、在 forward 中按你写的计算图顺序调用它们——并不存在物理意义上的"拼接"，子层之间是函数调用关系，不是结构连接。

from torch.utils.data import Dataset, DataLoader

class PretrainDataset(Dataset):
    def __len__(self):
        return len(self.samples)

    def __getitem__(self, idx):
        text = self.samples[idx]
        tokens = self.tokenizer(text)
        return torch.tensor(tokens[:-1]), torch.tensor(tokens[1:])
        # 输入是 [0..n-1]，目标是 [1..n]（预测下一个 token）

loader = DataLoader(dataset, batch_size=32, shuffle=True)
for input_ids, labels in loader:  # 每次取一个 batch
    loss = model(input_ids, labels=labels).loss

混合精度训练

定义：用 BF16 算前向，FP32 存权重 | 白话：算得快、省显存、精度不掉 | 用途：MiniMind 默认开启

# MiniMind 中的混合精度写法
scaler = torch.amp.GradScaler('cuda')

with torch.amp.autocast('cuda', dtype=torch.bfloat16):
    # 前向用 bf16（每个数 2 字节，比 fp32 的 4 字节省一半）
    res = model(input_ids, labels=labels)
    loss = res.loss

scaler.scale(loss).backward()    # 反向传播（自动缩放梯度）
scaler.step(optimizer)           # 更新参数（自动转回 fp32）
optimizer.zero_grad(set_to_none=True)

PyTorch 排错指南

shape 不匹配

症状：RuntimeError: mat1 and mat2 shapes cannot be multiplied

修复：打印 tensor.shape 逐步排查，对照数据流图检查维度

view() 报错

症状：RuntimeError: view size is not compatible

修复：先 .contiguous() 再 .view()，或直接 .reshape()

gradient is None

症状：loss.backward() 后 .grad 是 None

修复：确认 requires_grad=True；不在 no_grad() 内调用 backward()

CUDA OOM

症状：CUDA out of memory

修复：减小 batch_size；开启混合精度；用 del 释放不需要的张量

训练语言模型离不开几个关键的数学概念，但你完全不需要推导证明——只要能看懂公式在干什么、为什么需要它就够了。这一节用最直白的方式把这些概念讲清楚，后面真正遇到时不会一脸懵。

  • 线性代数 —— 矩阵乘法和点积是 Transformer 里最基本的运算，理解"维度对齐"就够了
  • 概率与 Softmax —— 模型输出的"下一个词的概率分布"是怎么算出来的
  • 交叉熵与损失函数 —— 用一个数字衡量"模型猜得有多离谱"
  • 梯度与链式法则 —— 为什么反向传播能自动算出每个参数该调多少

线性代数

神经网络的所有计算本质上是矩阵乘法

import torch

# 矩阵乘法：神经网络层的本质
x = torch.randn(1, 512, 768)   # 输入: (batch, seq_len, dim)
W = torch.randn(768, 768)      # 权重矩阵
y = x @ W.T                    # 线性变换: y = xW^T
print(y.shape)                  # (1, 512, 768)

# 点积：Attention 中衡量"相关性"
q = torch.randn(1, 512, 64)    # Query 向量
k = torch.randn(1, 512, 64)    # Key 向量
score = q @ k.transpose(-2,-1)  # 点积 → 注意力分数
print(score.shape)               # (1, 512, 512)
  • 向量：一列数字，如 [0.1, 0.5, -0.3]，可以理解为"方向"
  • 矩阵乘法：nn.Linear(768, 768) 本质就是 y = xW^T + b
  • 点积：衡量两个向量的"相似度"。Attention 中 Q·K 就是用点积算相关性

概率与 Softmax

语言模型的核心任务：预测下一个 token 的概率

import torch

# Softmax：把任意数字变成概率分布（加起来等于 1）
logits = torch.tensor([2.0, 1.0, 0.0])
probs = torch.softmax(logits, dim=-1)
print(probs)  # tensor([0.6654, 0.2447, 0.0900])
# 最大的 logits 对应最大的概率

# MiniMind 生成时：从概率分布中采样下一个 token
next_token = torch.multinomial(probs, num_samples=1)
  • 概率分布：所有可能性之和 = 1，softmax 保证这一点
  • 条件概率：语言模型就是 P(下一个词 | 前面的词)
  • 训练目标：让正确 token 的概率尽可能大

交叉熵与损失

衡量预测与真实差距的标尺——Loss 越小，模型越准

梯度与链式法则

训练能work的数学原理——你不需要手算，但需要直觉

import torch

# 梯度：告诉参数"往哪个方向调、调多少"
w = torch.randn(3, requires_grad=True)
loss = (w ** 2).sum()     # 前向：计算损失
loss.backward()            # 反向：自动求梯度
print(w.grad)              # tensor([2w1, 2w2, 2w3]) → ∂loss/∂w

# 链式法则：复合函数的导数 = 各层导数相乘
# 这就是"反向传播"的数学基础
# PyTorch 的 autograd 自动帮你算，你不需要手写
  • 导数：函数在某点的变化率。正 = 上升，负 = 下降
  • 梯度：多维导数，指向函数值增长最快的方向。训练沿梯度的反方向走
  • 链式法则：复合函数的导数 = 各层导数相乘。反向传播就是链式法则的自动执行
