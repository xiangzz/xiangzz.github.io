Tokenizer 分词器

文本如何变成数字？BPE 算法、词表构建、Chat Template 对话格式化——连接人类语言与机器语言的第一座桥。

核心 BPE 词表 6400

模型架构

逐行读懂 model_minimind.py —— 287 行代码浓缩 Transformer、RoPE、GQA、KV-Cache、MoE 全部精华。

核心 Transformer 287行

预训练 Pretraining

Next Token Prediction —— 让模型阅读大量文本，学会"根据前文预测下一个字"。这是所有 LLM 的基础能力。

核心 交叉熵 余弦LR
4

监督微调 SFT

把预训练模型微调为对话模型。关键技巧：Label Masking —— 只在 assistant 回答的部分计算 loss。

核心 对话能力 Label Mask
5

LoRA 参数高效微调

只训练 4% 的参数，就能获得接近全量微调的效果。低秩分解旁路的原理与实现。

参数高效 低秩分解 4%参数
6

知识蒸馏

用大模型（教师）的输出分布来指导小模型（学生）训练。温度缩放暴露"暗知识"。

教师-学生 KL散度 温度T

DPO 偏好优化

不需要奖励模型，直接用偏好数据（好/差回答对）对齐模型。Bradley-Terry 模型实战。

核心 偏好对齐 β=0.15

GRPO 与 PPO 强化学习

RLHF 的两种主流算法：GRPO 用组内相对优势简化训练；PPO 用 Actor-Critic 架构精确优化。

进阶 GAE Rollout

训练模型学会使用外部工具——计算器、天气查询、翻译。多轮 Rollout + 工具执行模拟。
