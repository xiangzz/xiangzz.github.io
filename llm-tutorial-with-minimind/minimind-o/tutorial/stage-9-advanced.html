Part 2：细节的演进

以注意力为例，看技术是怎么一步步优化的。

注意力的三代

MHA → GQA → MQA：在精度和速度间取舍

注意力头的 KV 数量，经历了三代设计。这背后是一个清晰的权衡：KV 越少，推理越快、缓存越小，但精度可能下降。

MHA（标准）

8 个 Q、8 个 K、8 个 V。

精度最高，但 KV Cache 最大。

适合训练、对质量要求高。

GQA（本项目）

8 个 Q、4 组 KV，两两共享。

精度几乎不损，缓存减半。

现代 LLM 主流选择。

MQA（极端）

8 个 Q、1 组 KV。

最快最小，但精度略降。

对速度极致追求时用。

GQA 是个漂亮的折中——这是工程里最常见的智慧：不走极端，在两个端点之间找甜点。

MiniMind-O 处在这条演进的终点——「全模态」。而 GPT-4o 这样的闭源模型走的是同一条路。区别只在于规模：GPT-4o 是万亿参数，MiniMind-O 是一亿参数。但核心思想是一致的，这正是开源小模型的价值——让你能看清大模型的「骨架」。

多 Token 预测

为什么能同时生成 8 层

传统生成是「一个一个 token 吐」。但 MiniMind-O 的 Talker 同时预测 8 层音频码——这叫多 Token 预测（MTP），是近两年的重要趋势。

传统：逐个生成

生成 token1 → token2 → ...

质量高，但慢。

MTP：一次多个

同时预测 8 层码本。

配合交错延迟保证质量，比逐层快约 8 倍。

这个思路在 GPT-4o、DeepSeek-V3 等最新模型里都被采用。MiniMind-O 是你能亲手研究 MTP 的最小实例。

2024-2025 的新进展

MiniMind-O 训练完成后，这个领域又有几条值得关注的新支线。不必现在读，但要知道它们存在，方便你规划下一步：

DeepSeek-V3 / R1

2024-2025 国产开源旗舰。V3 用 MoE + MTP（多 Token 预测，正是阶段 3 讲的 Talker 8 层码思路）做到极致性价比；R1 展示了纯 RL（强化学习）也能催生推理能力。阶段 3、5 学完可读。

Mamba / 线性注意力 / SSM

2023-2025 兴起的非 Transformer 路线：用状态空间模型或线性注意力替代标准注意力，长序列更省显存。MiniMind-O 没用，但它是 Transformer 之外的重要分支。作为视野扩展了解即可。

全模态新对照

除了 GPT-4o，2024-2025 还涌现 Qwen2.5-Omni、Step-Audio 等开源/半开源全模态模型。它们和 MiniMind-O 思路相通但规模更大、模态更多。阶段 6、7 学完、想对比时可查。

LLaMA 2 / 3 / 3.1

LLaMA 系列的后续演进：GQA 全面采用、上下文扩展到 128K、多语言增强。读完 LLaMA 原文想看「现代 LLM 怎么继续优化」时读。阶段 2 后可选。

这条支线不是必读——先把 MiniMind-O 吃透，再按兴趣挑。技术演进很快，但基础架构（Transformer + 注意力 + 位置编码）十几年没变，本教程讲的就是这个稳态的核心。
