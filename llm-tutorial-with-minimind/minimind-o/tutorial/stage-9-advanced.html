Part 2：细节的演进

以注意力为例，看技术是怎么一步步优化的。

注意力的三代

MHA → GQA → MQA：在精度和速度间取舍

注意力头的 KV 数量，经历了三代设计。这背后是一个清晰的权衡：KV 越少，推理越快、缓存越小，但精度可能下降。

MHA（标准）

8 个 Q、8 个 K、8 个 V。

精度最高，但 KV Cache 最大。

适合训练、对质量要求高。

GQA（本项目）

8 个 Q、4 组 KV，两两共享。

精度几乎不损，缓存减半。

现代 LLM 主流选择。

MQA（极端）

8 个 Q、1 组 KV。

最快最小，但精度略降。

对速度极致追求时用。

GQA 是个漂亮的折中——这是工程里最常见的智慧：不走极端，在两个端点之间找甜点。

MiniMind-O 处在这条演进的终点——「全模态」。而 GPT-4o 这样的闭源模型走的是同一条路。区别只在于规模：GPT-4o 是万亿参数，MiniMind-O 是一亿参数。但核心思想是一致的，这正是开源小模型的价值——让你能看清大模型的「骨架」。

多 Token 预测

为什么能同时生成 8 层

传统生成是「一个一个 token 吐」。但 MiniMind-O 的 Talker 同时预测 8 层音频码——这叫多 Token 预测（MTP），是近两年的重要趋势。

传统：逐个生成

生成 token1 → token2 → ...

质量高，但慢。

MTP：一次多个

同时预测 8 层码本。

配合交错延迟保证质量，比逐层快约 8 倍。

这个思路在 GPT-4o、DeepSeek-V3 等最新模型里都被采用。MiniMind-O 是你能亲手研究 MTP 的最小实例。

Part 4：论文阅读路线

想往深处走，这是按优先级排好的清单。

必读：打地基的两篇

1.《Attention Is All You Need》（2017）

Transformer 的诞生论文。所有后续工作的根基。读懂它，你就理解了 Q/K/V、多头、位置编码的原始设计动机。

2.《LLaMA》论文

MiniMind-O 架构的直接参考。RMSNorm、RoPE、SwiGLU 这些现代 LLM 的「标准配方」都在这里定型。读完你会发现 MiniMind-O 几乎是它的小型复刻。

推荐：理解每个零件

3.《RoFormer》—— RoPE 原始论文，想搞懂旋转位置编码的数学原理必读。

4.《GQA》论文—— 分组查询注意力，理解 KV Cache 优化的权衡。

5.《GLU Variants Improve Transformer》—— SwiGLU 的来源，理解门控前馈网络。

6.《Switch Transformer》—— MoE 混合专家的经典，理解稀疏激活。

进阶：全模态方向

7.《Mini-Omni》—— Thinker-Talker 架构、交错延迟音频生成的原始提出者，MiniMind-O 的直接蓝本。

8.《SpeechGPT》《SALMONN》—— 语音-语言模型的先驱，理解「为什么要把声音接进 LLM」。

9.《LLaVA》《MiniGPT-4》—— 视觉语言模型，理解视觉投影对齐的经典做法。

10.《Mimi》《SoundStream》—— 神经音频编解码器，理解 8 层 RVQ 码本的原理。

姊妹项目

MiniMind（纯文本 LLM）

最基础的一个。如果你对「预训练」(从零训练 LLM) 感兴趣，从这里开始最纯粹——没有多模态的干扰。
