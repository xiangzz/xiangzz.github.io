这是一个什么样的模型

MiniMind-O 是一个约 1 亿参数的全模态模型。和只能处理文字的普通 LLM 不同，它能：

👂 听懂语音

理解你说的每一句话，不只是文字。

👁️ 看懂图像

识别画面内容，给出描述。

💬 生成文字

像普通 LLM 一样回答问题、对话。

🎹 开口说话

用流式语音回复，还能模仿任意音色。

它的核心是 Thinker-Talker 双路径架构：一个 Thinker 负责「理解和想」，一个 Talker 负责「说出来」。这个设计浓缩了许多顶级模型（如 GPT-4o）的思路，但小到能在一张显卡上跑起来——这正是它作为教学项目的价值：让你看清全模态模型的每一个零件。
