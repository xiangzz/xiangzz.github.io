定义工具

用 tool() + zod 创建三个数学工具

import { ChatAnthropic } from "@langchain/anthropic";
import { tool } from "@langchain/core/tools";
import * as z from "zod";

const model = new ChatAnthropic({
  model: "claude-sonnet-4-6",
  temperature: 0,
});

// 加法工具
const add = tool(({ a, b }) => a + b, {
  name: "add",
  description: "Add two numbers",
  schema: z.object({
    a: z.number().describe("First number"),
    b: z.number().describe("Second number"),
  }),
});

// 乘法工具
const multiply = tool(({ a, b }) => a * b, {
  name: "multiply",
  description: "Multiply two numbers",
  schema: z.object({
    a: z.number().describe("First number"),
    b: z.number().describe("Second number"),
  }),
});

// 除法工具
const divide = tool(({ a, b }) => a / b, {
  name: "divide",
  description: "Divide two numbers",
  schema: z.object({
    a: z.number().describe("First number"),
    b: z.number().describe("Second number"),
  }),
});

// 按名称索引工具，绑定到模型
const toolsByName = { [add.name]: add, [multiply.name]: multiply, [divide.name]: divide };
const tools = Object.values(toolsByName);
const modelWithTools = model.bindTools(tools);
如果你看到报错：
  • AuthenticationError 或 Could not find API key → 确认已设置 ANTHROPIC_API_KEY 环境变量：$ export ANTHROPIC_API_KEY=sk-ant-...
  • NotFoundError: model "xxx" not found → 检查模型名称拼写是否正确，或尝试换一个可用模型
tool() 做了什么：把一个普通函数包装成 LLM 可调用的工具。zod schema 告诉模型这个工具接受什么参数——模型自己决定什么时候调用。

定义状态

MessagesValue 追踪对话，ReducedValue 追踪调用次数

import {
  StateGraph, StateSchema, MessagesValue, ReducedValue,
  GraphNode, ConditionalEdgeRouter, START, END,
} from "@langchain/langgraph";

const MessagesState = new StateSchema({
  // 消息历史 — 内置追加 reducer，新消息自动拼到末尾
  messages: MessagesValue,
  // LLM 调用计数 — 自定义 reducer，每次 +1
  llmCalls: new ReducedValue(
    z.number().default(0),
    { reducer: (x, y) => x + y }
  ),
});

MessagesValue

内置的消息追加器。节点返回 { messages: [newMsg] }，新消息自动拼到已有消息列表末尾。

ReducedValue

自定义 reducer 的字段。这里每次返回 { llmCalls: 1 }，reducer 把它加到已有值上。

模型节点

调用 LLM，把回复追加到消息历史

import { SystemMessage } from "@langchain/core/messages";

const llmCall: GraphNode<typeof MessagesState> = async (state) => {
  const response = await modelWithTools.invoke([
    new SystemMessage(
      "You are a helpful assistant tasked with performing arithmetic on a set of inputs."
    ),
    ...state.messages,
  ]);
  return {
    messages: [response],  // MessagesValue 自动追加
    llmCalls: 1,            // ReducedValue 累加 +1
  };
};
节点就是函数：接收当前状态，返回状态更新。你不需要手动操作整个状态——只需要返回你想修改的字段，LangGraph 的 reducer 会处理合并。

工具节点

执行模型请求的工具调用，把结果追加到消息历史

import { AIMessage, ToolMessage } from "@langchain/core/messages";

const toolNode: GraphNode<typeof MessagesState> = async (state) => {
  const lastMessage = state.messages.at(-1);

  // 安全检查：最后一条必须是 AI 消息
  if (lastMessage == null || !AIMessage.isInstance(lastMessage)) {
    return { messages: [] };
  }

  // 逐个执行工具调用
  const result: ToolMessage[] = [];
  for (const toolCall of lastMessage.tool_calls ?? []) {
    const tool = toolsByName[toolCall.name];
    const observation = await tool.invoke(toolCall);
    result.push(observation);
  }

  return { messages: result };
};
流程：模型说"我要调用 add(3, 4)"→ toolNode 执行 add → 返回结果 7 → 追加为 ToolMessage → 模型看到结果后决定下一步。

结束判断

条件边：模型还要调工具吗？

const shouldContinue: ConditionalEdgeRouter<
  typeof MessagesState, "toolNode"
> = (state) => {
  const lastMessage = state.messages.at(-1);

  // 不是 AI 消息 → 结束
  if (!lastMessage || !AIMessage.isInstance(lastMessage)) {
    return END;
  }

  // AI 请求了工具调用 → 去执行工具
  if (lastMessage.tool_calls?.length) {
    return "toolNode";
  }

  // AI 没有请求工具 → 回复用户，结束
  return END;
};
条件边的逻辑：看完最后一条消息。如果 AI 说了"我要调工具"，就去 toolNode；如果 AI 直接给了答案，就结束。

组装智能体

把所有零件拼成一个完整的图

const agent = new StateGraph(MessagesState)
  .addNode("llmCall", llmCall)
  .addNode("toolNode", toolNode)
  .addEdge(START, "llmCall")
  .addConditionalEdges("llmCall", shouldContinue, ["toolNode", END])
  .addEdge("toolNode", "llmCall")
  .compile();

关键连线：toolNode → llmCall 形成循环。工具执行完后，模型需要看到结果才能决定下一步——继续调工具，还是给用户最终答案。

运行测试

用一句话启动智能体

import { HumanMessage } from "@langchain/core/messages";

const result = await agent.invoke({
  messages: [new HumanMessage("Add 3 and 4.")],
});

// 打印完整的消息历史
for (const message of result.messages) {
  console.log(`[${message.type}]: ${message.text}`);
}
# 预期输出：
[human]: Add 3 and 4.
[ai]: [调用 add 工具, a=3, b=4]
[tool]: 7
[ai]: The answer is 7.
# llmCalls: 2（模型被调用了两次）
发生了什么：用户说"Add 3 and 4"→ 模型决定调用 add(3,4) → 工具返回 7 → 模型看到结果，回答"The answer is 7"。模型被调用了两次（第一次决定调工具，第二次生成最终答案）。

排错指南

API Key 报错

症状：AuthenticationError: Invalid API Key

修复：检查环境变量 ANTHROPIC_API_KEY 是否设置正确。

工具名找不到

症状：Tool not found: add

修复：确认 toolsByName 的 key 和工具的 name 属性一致。注意大小写。

消息类型错误

症状：lastMessage.tool_calls is not a function

修复：先检查 AIMessage.isInstance(lastMessage)，不是所有消息都有 tool_calls。

无限循环

症状：智能体一直调工具，不停止。

修复：检查 shouldContinue 逻辑——确保模型不调工具时返回 END，而不是继续循环。
