包装类概述与继承体系

包装类的基本概念：Java并不是纯面向对象的语言，基本数据类型不是面向对象的。Java提供了基本类型包装类，使得基本类型能够支持对象操作！

基本类型与包装类对应关系：

  • byte → Byte
  • boolean → Boolean
  • short → Short
  • char → Character
  • int → Integer
  • long → Long
  • float → Float
  • double → Double

包装类继承体系

Number抽象类： Number 类是 Byte, Short, Integer, Long, Float, Double 这些数字包装类的抽象父类。

为什么需要包装类？

  • 泛型支持： 泛型参数必须使用对象类型
  • null值表示： 基本类型不能为null，包装类可以
  • 工具方法： 提供丰富的静态工具方法（进制转换、字符串解析等）
  • 面向对象特性： 支持继承、多态等OOP特性
  • 集合框架应用： 集合只能存储对象

Number类的核心方法

Number抽象类提供了一系列用于将包装的数值转换为基本数据类型的方法：

数值转换方法：

  • byte byteValue() - 返回byte值
  • short shortValue() - 返回short值
  • int intValue() - 返回int值
  • long longValue() - 返回long值
  • float floatValue() - 返回float值
  • double doubleValue() - 返回double值

设计特点：

  • 所有数字包装类都继承这些方法
  • 支持灵活的类型转换
  • 为多态编程提供基础
  • 统一了数值操作的接口

public class BoxingUnboxingProcess {

    public static void main(String[] args) {
        // 1. 自动装箱
        Integer num1 = 10;             // Integer.valueOf(10)
        Integer num2 = 20;             // Integer.valueOf(20)

        // 2. 运算中的装箱拆箱
        Integer sum = num1 + num2;     // 详细过程：
                                        // a) num1拆箱 -> 10
                                        // b) num2拆箱 -> 20
                                        // c) 基本运算 -> 30
                                        // d) 结果装箱 -> valueOf(30)

        // 3. 混合类型运算
        int result = num1 * 2;         // num1拆箱 -> 10 * 2 = 20

        // 4. 条件判断
        if (sum > num1) {              // sum和num1都拆箱比较
            System.out.println("sum > num1");
        }

        // 5. 方法参数传递
        processNumber(sum);            // sum拆箱传递给int参数
    }

    static void processNumber(int number) {
        System.out.println("处理数字: " + number);
    }
}

包装类缓存机制详解

包装类 缓存范围 是否可配置 缓存对象数 特点
Byte -128~127 否 256个 全部值缓存
Short -128~127 否 256个 部分值缓存
Integer -128~127 是 默认256个 可扩展缓存范围
Long -128~127 否 256个 部分值缓存
Character \u0000~\u007F 否 128个 ASCII字符集
Boolean true, false 否 2个 两个单例对象
Float/Double 无 N/A 0个 没有缓存机制

Integer缓存源码分析

// Integer类内部实现（简化版）
private static class IntegerCache {
    static final int low = -128;
    static final int high;
    static final Integer cache[];

    static {
        // 1. 默认缓存范围
        int h = 127;

        // 2. 支持JVM参数配置缓存上限
        String integerCacheHighPropValue =
            sun.misc.VM.getSavedProperty("java.lang.Integer.IntegerCache.high");

        if (integerCacheHighPropValue != null) {
            try {
                int i = parseInt(integerCacheHighPropValue);
                i = Math.max(i, 127);  // 至少127
                h = Math.min(i, Integer.MAX_VALUE - (-low) -1);
            } catch( NumberFormatException nfe) {
                // 配置错误时使用默认值127
            }
        }
        high = h;

        // 3. 创建缓存数组
        cache = new Integer[(high - low) + 1];
        int j = low;
        for(int k = 0; k < cache.length; k++)
            cache[k] = new Integer(j++);
    }
}

// valueOf方法如何使用缓存
public static Integer valueOf(int i) {
    if (i >= IntegerCache.low && i <= IntegerCache.high)
        return IntegerCache.cache[i + (-IntegerCache.low)];
    return new Integer(i);
}

异常处理：安全的数字转换

public class SafeNumberConversion {

    // 1. NumberFormatException安全处理
    public static Integer safeParseInt(String str) {
        if (str == null || str.trim().isEmpty()) {
            return null;
        }

        try {
            return Integer.parseInt(str);
        } catch (NumberFormatException e) {
            System.err.println("无法转换 '" + str + "' 为整数: " + e.getMessage());
            return null;
        }
    }

    // 2. 带默认值的转换
    public static int parseIntWithDefault(String str, int defaultValue) {
        try {
            return Integer.parseInt(str);
        } catch (NumberFormatException | NullPointerException e) {
            return defaultValue;
        }
    }

    // 3. 多次尝试不同格式
    public static Double parseFlexible(String input) {
        if (input == null) return null;

        // 尝试直接解析
        try {
            return Double.parseDouble(input);
        } catch (NumberFormatException e1) {
            // 尝试去除逗号等格式化字符
            try {
                String clean = input.replaceAll("[,\\s]", "");
                return Double.parseDouble(clean);
            } catch (NumberFormatException e2) {
                System.err.println("无法解析数字: " + input);
                return null;
            }
        }
    }

    public static void main(String[] args) {
        String[] inputs = {"123", "1,234", "abc", "", null, "-999"};

        System.out.println("=== 安全转换演示 ===");
        for (String input : inputs) {
            System.out.print("输入: '" + input + "' -> ");
            Integer result = safeParseInt(input);
            System.out.println("结果: " + result);

            // 带默认值的转换
            int safeResult = parseIntWithDefault(input, 0);
            System.out.println("默认值结果: " + safeResult);
            System.out.println();
        }
    }
}

NullPointerException防范策略

public class NullSafetyStrategies {

    // ❌ 危险的写法
    public static int dangerousSum(Integer a, Integer b) {
        return a + b;  // NPE风险
    }

    // ✅ 安全的null处理方式
    public static int safeSum(Integer a, Integer b) {
        // 方式1：三元运算符
        int intA = (a != null) ? a : 0;
        int intB = (b != null) ? b : 0;
        return intA + intB;
    }

    // ✅ 使用Objects工具类
    public static int safeSumWithObjects(Integer a, Integer b) {
        int intA = java.util.Objects.requireNonNullElse(a, 0);
        int intB = java.util.Objects.requireNonNullElse(b, 0);
        return intA + intB;
    }

    // ✅ 使用Optional处理
    public static Optional<Integer> safeMultiply(Optional<Integer> a, Optional<Integer> b) {
        return a.flatMap(valA ->
                 b.map(valB -> valA * valB));
    }

    // ✅ 工具方法：安全的拆箱
    public static int safeUnbox(Integer value, int defaultValue) {
        return (value != null) ? value : defaultValue;
    }

    // ✅ 批量处理中的null安全
    public static double averageSafely(List<Integer> numbers) {
        if (numbers == null || numbers.isEmpty()) {
            return 0.0;
        }

        return numbers.stream()
                      .filter(java.util.Objects::nonNull)  // 过滤null值
                      .mapToInt(Integer::intValue)
                      .average()
                      .orElse(0.0);
    }

    public static void main(String[] args) {
        // 测试各种null安全方法
        System.out.println("危险求和: " + dangerousSum(10, null));    // 抛NPE
        System.out.println("安全求和: " + safeSum(10, null));          // 10
        System.out.println("Objects求和: " + safeSumWithObjects(null, 20)); // 20

        Optional<Integer> result = safeMultiply(Optional.of(5), Optional.of(3));
        System.out.println("Optional乘法: " + result.orElse(0));    // 15

        List<Integer> numbers = Arrays.asList(10, null, 20, 30, null);
        System.out.println("安全平均: " + averageSafely(numbers));     // 20.0
    }
}

大整数：BigInteger

重要说明：BigInteger不是包装类，它没有对应的基本数据类型！

特点与示例：

  • 任意精度整数：大小理论上只受内存限制。 
    // 演示：计算一个超出long范围的数
BigInteger largeNum = new BigInteger("123456789012345678901234567890");
BigInteger result = largeNum.multiply(largeNum);
System.out.println(result); // 输出一个非常巨大的数字
  • 不支持运算符：必须使用方法进行运算。 
    BigInteger a = BigInteger.valueOf(100);
BigInteger b = BigInteger.valueOf(50);
// BigInteger c = a + b; // 编译错误！
BigInteger c = a.add(b);    // 正确方式
System.out.println(c); // 输出: 150
  • 不可变对象：每次运算都产生新对象。 
    BigInteger num = BigInteger.valueOf(10);
num.add(BigInteger.valueOf(5)); // 这行代码不改变num的值
System.out.println(num); // 仍然输出: 10

BigInteger newNum = num.add(BigInteger.valueOf(5)); // 必须接收返回值
System.out.println(newNum); // 输出: 15

适用场景：需要处理超出long范围的整数计算，如加密、科学计算等。

public class FloatingPointProblem {

    public static void main(String[] args) {
        System.out.println("=== 浮点数精度问题演示 ===");

        // 问题1：简单的加法运算
        double a = 0.1;
        double b = 0.2;
        double c = a + b;
        System.out.println("0.1 + 0.2 = " + c);  // 输出: 0.30000000000000004

        // 问题2：金融计算中的误差累积
        double money = 0.0;
        for (int i = 0; i < 10; i++) {
            money += 0.1;  // 误差会累积
        }
        System.out.println("10次0.1相加: " + money);  // 输出: 0.9999999999999999

        // 问题3：比较运算的陷阱
        double d1 = 0.0;
        for (int i = 0; i < 10; i++) {
            d1 += 0.1;
        }
        System.out.println("d1 == 1.0: " + (d1 == 1.0));  // 输出: false

        System.out.println("\n=== BigDecimal解决方案 ===");

        // 解决方案：使用BigDecimal
        BigDecimal bd1 = new BigDecimal("0.1");
        BigDecimal bd2 = new BigDecimal("0.2");
        BigDecimal bd3 = bd1.add(bd2);
        System.out.println("BigDecimal 0.1 + 0.2 = " + bd3);  // 输出: 0.3

        BigDecimal moneyBD = BigDecimal.ZERO;
        BigDecimal tenCents = new BigDecimal("0.1");
        for (int i = 0; i < 10; i++) {
            moneyBD = moneyBD.add(tenCents);
        }
        System.out.println("BigDecimal 10次0.1相加: " + moneyBD);  // 输出: 1.0
    }
}

3. 基本运算操作

public class BigDecimalOperations {

        // 乘法

        // 除法 - 需要指定精度和舍入模式
        BigDecimal quotient = a.divide(b, 2, RoundingMode.HALF_UP);

5. 实际应用：货币计算

import java.math.BigDecimal;
import java.math.RoundingMode;
import java.util.Arrays;

public class CurrencyCalculator {

    // 货币计算工具类
    public static class Money {
        private final BigDecimal amount;

        public Money(String amount) {
            this.amount = new BigDecimal(amount).setScale(2, RoundingMode.HALF_UP);
        }

        public Money add(Money other) {
            return new Money(this.amount.add(other.amount).toString());
        }

        public Money multiply(BigDecimal multiplier) {
            BigDecimal result = this.amount.multiply(multiplier).setScale(2, RoundingMode.HALF_UP);
            return new Money(result.toString());
        }

        public Money divide(BigDecimal divisor) {
            BigDecimal result = this.amount.divide(divisor, 2, RoundingMode.HALF_UP);
            return new Money(result.toString());
        }

        @Override
        public String toString() {
            return "¥" + amount;
        }
    }

    public static void main(String[] args) {
        // 购物车计算示例
        Money apple = new Money("5.99");
        Money banana = new Money("3.50");
        Milk milk = new Money("12.80");  // 假设有Milk类

        Money subtotal = apple.add(banana).add(milk);
        Money tax = subtotal.multiply(new BigDecimal("0.08"));  // 8%税率
        Money total = subtotal.add(tax);

        System.out.println("商品明细:");
        System.out.println("苹果: " + apple);
        System.out.println("香蕉: " + banana);
        System.out.println("牛奶: " + milk);
        System.out.println("小计: " + subtotal);
        System.out.println("税费: " + tax);
        System.out.println("总计: " + total);

        // 平均分摊
        BigDecimal peopleCount = new BigDecimal("3");
        Money perPerson = total.divide(peopleCount);
        System.out.println("每人应付: " + perPerson);
    }
}

class Milk extends Money {
    public Milk(String price) {
        super(price);
    }
}

实战项目：数据分析工具

项目背景： 实现一个简单的数据分析工具，统计数字列表的各种统计信息

完整代码示例

import java.util.*;
import java.util.stream.*;

public class DataAnalyzer {
    private List<Double> data;

    public DataAnalyzer() {
        this.data = new ArrayList<>();
    }

    // 添加数据点
    public void addDataPoint(double value) {
        data.add(value);  // 自动装箱：double -> Double
    }

    // 计算平均值
    public Double getAverage() {
        if (data.isEmpty()) return null;  // 可以返回null
        return data.stream()
                  .mapToDouble(Double::doubleValue)  // 拆箱操作
                  .average()
                  .orElse(0.0);
    }

    // 获取最大值
    public Double getMax() {
        return Collections.max(data);  // 比较时使用Double.compareTo()
    }

    // 找出所有大于平均值的数
    public List<Double> getAboveAverage() {
        Double avg = getAverage();
        return data.stream()
                  .filter(d -> d.compareTo(avg) > 0)  // 使用包装类的比较方法
                  .collect(Collectors.toList());
    }

    public static void main(String[] args) {
        DataAnalyzer analyzer = new DataAnalyzer();

        // 添加测试数据
        double[] testData = {1.5, 2.7, 3.1, 4.8, 2.2, 5.0, 1.9};
        for (double num : testData) {
            analyzer.addDataPoint(num);
        }

        System.out.println("平均值: " + analyzer.getAverage());
        System.out.println("最大值: " + analyzer.getMax());
        System.out.println("高于平均值的数: " + analyzer.getAboveAverage());
    }
}
