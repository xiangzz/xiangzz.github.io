## I/O（摘录）

### Java IO 流了解吗？

I/O 即 `Input / Output`，输入和输出。

- 数据进入内存：输入
- 数据从内存输出到文件、数据库、网络：输出

Java 中，I/O 流按方向分：

- 输入流
- 输出流

按处理单位分：

- 字节流
- 字符流

Java I/O 体系的 4 个核心抽象基类：

- `InputStream`
- `OutputStream`
- `Reader`
- `Writer`

### I/O 流为什么要分为字节流和字符流？

- 字符流会帮你做字节到字符的转换
- 编码未知时，直接用字节流处理文本很容易出现乱码

结论：

- 处理二进制数据用字节流
- 处理文本数据更适合字符流

### BIO、NIO 和 AIO 的区别？

- BIO：同步阻塞 I/O
- NIO：同步非阻塞 I/O
- AIO：异步非阻塞 I/O

## 补充高频面试题（IO 体系）

### 1) 装饰器设计模式在 IO 里怎么体现？

- Java IO 中大量“包装流”用于在不改动原有流类型的前提下叠加能力（缓冲、字符解码、数据格式化等）。
- 面试回答重点：为什么不把所有能力塞进一个巨大的基类？因为组合比继承更灵活。

### 2) 为什么使用缓冲流通常能提升性能？

- 减少系统调用次数：小块多次读写会触发大量 I/O 调用。
- 缓冲流会把多次小 I/O 合并为更少的大 I/O，降低开销。

### 3) 字符编码相关的面试点有哪些？

- 字节与字符不是一回事：文本必须“按编码解码”才有意义。
- 常见追问：为什么同一个文件在不同机器上读出来乱码？本质是编码/解码不一致。

### 4) try-with-resources 为什么推荐？

- 能保证资源在作用域结束时被正确关闭（包括异常路径）。
- 代码更短、遗漏 `close()` 的风险更低。
