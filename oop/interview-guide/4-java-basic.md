## 基本语法（摘录）

### 注释有哪几种形式？

Java 中常见注释有三种：

```java
// 单行注释

/*
 * 多行注释
 */

/**
 * 文档注释
 */
```

### 标识符和关键字的区别是什么？

- 标识符：程序员自己起的名字
- 关键字：Java 已经赋予特殊语义的保留单词

### 自增自减运算符

`++`、`--` 可以写在变量前，也可以写在变量后：

- 前缀：先加减，再参与运算
- 后缀：先参与运算，再加减

### 移位运算符

Java 中有三种移位运算符：

- `<<`：左移
- `>>`：带符号右移
- `>>>`：无符号右移

### continue、break 和 return 的区别是什么？

- `continue`：跳出当前这一次循环，进入下一次循环
- `break`：跳出整个循环体
- `return`：结束当前方法

## 变量（摘录）

### 成员变量与局部变量的区别？

#### 语法形式

- 成员变量定义在类中、方法外
- 局部变量定义在方法、代码块或参数位置

#### 存储方式

- 静态成员变量属于类
- 非静态成员变量属于实例
- 局部变量通常位于栈帧中

#### 默认值

- 成员变量有默认值
- 局部变量没有默认值，必须先赋值再使用
