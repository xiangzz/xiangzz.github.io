## 重载与重写（摘录）

### 重载和重写有什么区别？

#### 重载（Overloading）

- 发生在同一个类中
- 方法名相同
- 参数列表必须不同
- 返回值类型可以不同

#### 重写（Overriding）

- 发生在父类与子类之间
- 方法名和参数列表必须相同
- 返回类型要相同，或是其子类
- 子类访问权限不能低于父类

一句话总结：

- 重载：同名不同参
- 重写：子类改写父类已有方法实现

## 可变长参数（摘录）

### 什么是可变长参数？

可变长参数允许方法接收不定数量的同类型参数。

```java
public static void method1(String... args) {
    // ...
}
```

规则：

- 可变参数必须是最后一个参数
- 编译后本质上会被转换成数组

## 值传递（摘录）

### Java 中只有值传递吗？

是的，Java 只有值传递。

#### 传基本类型

- 传的是值的副本
- 方法内部修改不影响外部变量

#### 传引用类型

- 传的仍然是值（对象地址的副本）
- 可以通过它修改对象内容
- 但不能改变外部引用本身的指向
