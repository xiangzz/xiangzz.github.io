## 本节对应的面试考点（摘录）

当前 interview-guide 原始资料对“数组声明/初始化/遍历/排序”等覆盖较少，但在“可变参”和“值传递”里涉及了数组的两个高频误区。

### 可变参数的本质

- 可变参数必须是最后一个参数
- 编译后本质上会被转换成数组

### 引用类型的值传递（以数组为例）

```java
public static void change(int[] array) {
    array[0] = 0;
}
```

要点：

- 传递的是“引用值的副本”
- 所以能改到原数组的内容
- 但改不了外部变量的“指向”
