## 基本类型（摘录）

### Java 中的几种基本数据类型了解么？

Java 有 8 种基本数据类型：

- `byte`
- `short`
- `int`
- `long`
- `float`
- `double`
- `char`
- `boolean`

### 基本类型和包装类型的区别？

主要差异体现在：

- 用途：包装类型可用于泛型，基本类型不可以
- 存储方式：包装类型属于对象，通常在堆中
- 默认值：包装类型默认值是 `null`，基本类型有默认值
- 比较方式：包装类型之间比较值优先用 `equals()`

## 包装类型缓存（摘录）

### 包装类型的缓存机制了解么？

默认缓存范围：

- `Byte`、`Short`、`Integer`、`Long`：`-128 ~ 127`
- `Character`：`0 ~ 127`
- `Boolean`：直接复用 `TRUE` / `FALSE`

## 拆装箱（摘录）

### 自动装箱与拆箱了解吗？原理是什么？

- 装箱：基本类型转包装类型（通常调用 `valueOf()`）
- 拆箱：包装类型转基本类型（通常调用 `xxxValue()`）

## 精度与大数（摘录）

### 为什么浮点数运算的时候会有精度丢失的风险？

因为很多十进制小数无法被二进制精确表示，只能被截断存储。

### 如何解决浮点数运算的精度丢失问题？

使用 `BigDecimal`。

### 超过 long 整型的数据应该如何表示？

使用 `BigInteger`。
