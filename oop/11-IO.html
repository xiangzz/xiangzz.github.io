File类基础概念

File 类是Java中用于表示文件系统中的文件或目录路径名的抽象表示。它提供了一个与平台无关的方式来处理文件和目录。

📦 核心概念：File类的双重身份

File对象可以表示两种类型：

📄 文件

存储数据的实际文件（如：test.txt、image.jpg）

new File("data.txt")

📁 目录

包含其他文件和子目录的文件夹

new File("docs")

⚠️ 注意：File对象本身只是路径的抽象表示，创建File对象并不会在文件系统中创建实际的文件或目录！

🏗️ 构造方法

// 1. 表示文件
File file1 = new File("D:\\workspace\\test.txt");

// 2. 表示目录
File dir1 = new File("D:\\workspace\\docs");

// 3. 使用父目录和子路径
File file2 = new File("D:\\workspace", "test.txt");

// 4. 使用File对象和子路径
File parent = new File("D:\\workspace");
File file3 = new File(parent, "test.txt");

// 5. 路径分隔符的跨平台处理
String path = "docs" + File.separator + "data" + File.separator + "config.txt";

// 判断File对象表示的是文件还是目录
System.out.println(file1.isFile());  // true（如果是文件）
System.out.println(file1.isDirectory());  // false
System.out.println(dir1.isDirectory());  // true（如果是目录）
System.out.println(dir1.isFile());  // false

⚠️ 重要概念

  • 抽象表示：File对象不一定对应真实存在的文件
  • 路径分隔符：Windows使用\，Linux/macOS使用/
  • 相对路径 vs 绝对路径：相对于当前工作目录 vs 从根目录开始
  • 规范路径：解析.和..后的标准路径

File类只是路径的抽象，不创建实际文件。真正的文件操作需要其他IO类配合。

File类：路径

File类提供了丰富的方法来获取路径信息和文件名称。

public static void main(String[] args) throws IOException {
    // 创建测试文件
    File file = new File("./test/../docs/data.txt");
    file.getParentFile().mkdirs();
    file.createNewFile();

    // 路径相关方法
    // "data.txt"
    System.out.println("getName(): " + file.getName());  
    // "./test/../docs/data.txt" 
    System.out.println("getPath(): " + file.getPath());   
    // 完整绝对路径
    System.out.println("getAbsolutePath(): " + file.getAbsolutePath()); 
    // 规范化路径
    System.out.println("getCanonicalPath(): " + file.getCanonicalPath()); 

    // 父目录相关
    // "./test/../docs"
    System.out.println("getParent(): " + file.getParent());       
    File parent = file.getParentFile();
    // "docs"
    System.out.println("父目录名: " + parent.getName());           

    // 磁盘空间信息
    File root = new File("C:");
    long toGB = 1024 * 1024 * 1024;
    System.out.println("总空间: " + root.getTotalSpace() / toGB + " GB");
    System.out.println("可用空间: " + root.getFreeSpace() / toGB + " GB");
    System.out.println("可用空间: " + root.getUsableSpace() / toGB + " GB");
}

File类：状态

检查文件状态、获取文件属性是文件操作的第一步。

public static void analyzeFile(String filePath) {
    File file = new File(filePath);

    // 存在性检查
    if (!file.exists()) {
        System.out.println("文件不存在: " + filePath);
        return;
    }

    // 类型判断
    System.out.println("是文件: " + file.isFile());
    System.out.println("是目录: " + file.isDirectory());
    System.out.println("是绝对路径: " + file.isAbsolute());
    System.out.println("是隐藏文件: " + file.isHidden());

    // 权限检查
    System.out.println("可读: " + file.canRead());
    System.out.println("可写: " + file.canWrite());
    System.out.println("可执行: " + file.canExecute());

    // 文件属性
    System.out.println("文件大小: " + file.length() + " 字节");

    // 时间戳处理
    long lastModified = file.lastModified();
    Date date = new Date(lastModified);
    System.out.println("最后修改时间: " + 
        new SimpleDateFormat("yyyy-MM-dd HH:mm:ss").format(date));

    // 如果是目录，显示文件数量
    if (file.isDirectory()) {
        String[] files = file.list();
        System.out.println("目录下的文件数量: " 
            + (files != null ? files.length : 0));
    }
}

  • 磁盘空间管理：大文件处理前检查剩余空间
  • 文件监控：通过时间戳检测文件变化
  • 权限验证：确保程序有足够权限操作文件

📁 创建和删除操作

public static void fileOperationsDemo() throws IOException {
    // 1. 创建文件
    File file = new File("temp.txt");
    if (file.createNewFile()) {
        System.out.println("文件创建成功: " + file.getName());
    } else {
        System.out.println("文件已存在或创建失败");
    }

    // 2. 创建目录
    File dir = new File("mydir");
    if (dir.mkdir()) {
        System.out.println("单级目录创建成功");
    }

    // 3. 创建多级目录
    File multiDir = new File("path/to/deep/directory");
    if (multiDir.mkdirs()) {
        System.out.println("多级目录创建成功");
    }

    // 4. 删除文件
    if (file.delete()) {
        System.out.println("文件删除成功");
    }

    // 5. 程序退出时删除
    File tempFile = File.createTempFile("temp", ".txt");
    tempFile.deleteOnExit(); // JVM退出时自动删除

    // 6. 重命名/移动文件
    File oldFile = new File("old.txt");
    File newFile = new File("new.txt");
    if (oldFile.renameTo(newFile)) {
        System.out.println("文件重命名成功");
    }
}

⚠️ 常见陷阱

  • delete()不能删除非空目录，需要递归删除
  • renameTo()不能跨文件系统移动文件

public class TreeCommand {
    public static void main(String[] args) {
        File rootDir = new File("C:\\users\\Administrator\\IdeaProjects\\untitled1");
        printTree(rootDir, "");
    }

    private static void printTree(File dir, String prefix) {
        if (!dir.exists() || !dir.isDirectory()) {
            System.out.println("目录不存在或不是一个目录");
            return;
        }

        System.out.println(prefix + dir.getName() + ":");

        File[] files = dir.listFiles();
        if (files == null) {
            return;
        }

        for (int i = 0; i < files.length; i++) {
            boolean isLast = (i == files.length - 1);
            String newPrefix = prefix + "|    ";
            String connector = isLast ? "|---- " : "|---- ";

            if (files[i].isDirectory()) {
                printTree(files[i], newPrefix);
            } else {
                System.out.println(newPrefix + connector + files[i].getName());
            }
        }
    }
}

IO流概述

Java IO采用流(Stream)的概念来处理数据的输入输出。

流就像数据传输的管道，数据从源头流向目的地。

🌊 流的基本概念

  • 单向性：输入流只能读取，输出流只能写入
  • 顺序性：数据按顺序传输，支持随机访问的特殊类除外
  • 缓冲机制：提高I/O效率的关键
  • 装饰器模式：通过组合增强功能

字节流基础 - InputStream

InputStream 是所有字节输入流的抽象基类，定义了读取字节数据的基本规范。

📥 InputStream 抽象类的核心方法

函数头 功能 备注
public abstract int read() 读取单个字节 返回 0-255，流末尾返回 -1；效率较低，通常用于读取少量数据
public int read(byte[] b) 读取字节数组 批量读取，比单字节读取效率更高，会填充整个数组或直到流末尾
public int read(byte[] b, int off, int len) 读取指定长度的字节数组 精确控制读取位置和长度，常用于处理协议数据或文件格式
public long skip(long n) 跳过指定字节数 用于快速跳过不需要的数据，比读取并丢弃更高效；返回实际跳过的字节数
public int available() 返回可读取的字节数 仅是估计值，不应依赖其精确性，用于优化读取策略
public void close() 关闭流，释放系统资源 必须调用此方法释放文件句柄等资源，建议使用 try-with-resources
public void mark(int readlimit) 标记当前位置 并非所有流都支持标记功能，使用前应调用 markSupported() 检查
public void reset() 重置到最后一次 mark() 的位置 如果没有调用过 mark() 或标记已失效，会抛出 IOException

字节流基础 - OutputStream

OutputStream 是所有字节输出流的抽象基类，负责将字节数据写入目的地。

📤 OutputStream 抽象类的核心方法

函数头 功能 备注
public abstract void write(int b) 写入单个字节 最基础的写入方法，每次只写一个字节，取参数低8位；效率较低

public void write(byte[] b, int off, int len) 写入字节数组的一部分 精确控制写入内容，常用于分块写入大文件

public void close() 关闭流，释放资源 关闭前通常会自动调用 flush()，但建议显式调用 flush()

FileInputStream 和 FileOutputStream 是用于文件读写字节数据的基础流类，是字节流体系中的节点流。

public static void efficientFileCopy(String source, String target) {
    try (BufferedInputStream bis = new BufferedInputStream(
             new FileInputStream(source), 65536); // 64KB读取缓冲区

             new FileOutputStream(target), 65536)) { // 64KB写入缓冲区

🚨 常见陷阱与解决方案

陷阱1：忘记flush()

问题：使用BufferedOutputStream时，数据可能还在缓冲区中未写入磁盘

解决：关键数据后调用flush()，或在try-with-resources结束时自动flush

陷阱2：缓冲区过大

问题：过大的缓冲区占用过多内存，可能导致GC压力

解决：根据文件大小和系统内存合理选择缓冲区大小

陷阱3：装饰器顺序错误

问题：错误的装饰器顺序可能导致缓冲失效

解决：确保缓冲流装饰基础流，而不是被其他流装饰

正确使用缓冲流可以显著提升IO性能。关键是选择合适的缓冲区大小，养成良好的使用习惯，避免常见陷阱。

public void write(String str, int off, int len) 写入字符串的一部分 从指定偏移量开始写入指定长度的字符，常用于截取写入
public Writer append(CharSequence csq) 追加字符序列 支持链式调用，返回 Writer 本身，方便连续写入
public abstract void flush() 刷新缓冲区，强制写入 将缓冲区的字符编码并写入底层流，对于带缓冲的流非常重要
public abstract void close() 关闭流，释放资源 关闭前会自动调用 flush()，释放文件句柄等系统资源

字符流是处理文本数据的最佳选择，自动处理编码转换，支持Unicode字符。它本质上是"字节流 + 编码表"的封装，专门用于Text IO场景。

// 自动检测文件编码（简单示例）
public static String detectEncoding(String filePath) {
    try (FileInputStream fis = new FileInputStream(filePath)) {
        byte[] bom = new byte[4];
        int bytesRead = fis.read(bom);

        if (bytesRead >= 3 && bom[0] == (byte) 0xEF &&
            bom[1] == (byte) 0xBB && bom[2] == (byte) 0xBF) {
            return "UTF-8";
        }

        if (bytesRead >= 2 && bom[0] == (byte) 0xFE &&
            bom[1] == (byte) 0xFF) {
            return "UTF-16BE";
        }

        if (bytesRead >= 2 && bom[0] == (byte) 0xFF &&
            bom[1] == (byte) 0xFE) {
            return "UTF-16LE";
        }

        // 默认使用系统编码或UTF-8
        return StandardCharsets.UTF_8.name();

    } catch (IOException e) {
        return StandardCharsets.UTF_8.name();
    }
}

public class CountingInputStream extends FilterInputStream {
    private long bytesRead = 0;

    public CountingInputStream(InputStream in) {
        super(in);
    }

    @Override
    public int read() throws IOException {
        int data = super.read();
        if (data != -1) {
            bytesRead++;
        }
        return data;
    }

    @Override
    public int read(byte[] b, int off, int len) throws IOException {
        int count = super.read(b, off, len);
        if (count != -1) {
            bytesRead += count;
        }
        return count;
    }

    public long getBytesRead() {
        return bytesRead;
    }

    public void resetCount() {
        bytesRead = 0;
    }
}

Scanner类：文本扫描与解析

🤔 为什么有了 Reader 还需要 Scanner？

Reader 只是数据的"搬运工"，它只负责把字符读进内存，不关心内容是什么。如果你想从文本中读取一个整数，你需要自己处理空格分割、字符串转换等繁琐工作。

Scanner 是数据的"翻译官"，它不仅能读取数据，还能理解数据。它内置了强大的正则表达式引擎，能自动跳过分隔符（默认空格/换行），并直接将文本解析为 Java 类型（int, double 等）。

public static void parseCSVFile(String filePath) {
    try (Scanner scanner = new Scanner(new File(filePath))) {

        // 设置分隔符为逗号
        scanner.useDelimiter(",");

        int lineNumber = 0;
        while (scanner.hasNextLine()) {
            lineNumber++;
            String line = scanner.nextLine();

            // 跳过空行和注释行
            if (line.trim().isEmpty() || line.startsWith("#")) {
                continue;
            }

            // 解析CSV行
            Scanner lineScanner = new Scanner(line);
            lineScanner.useDelimiter(",");

            List fields = new ArrayList<>();
            while (lineScanner.hasNext()) {
                fields.add(lineScanner.next().trim());
            }

            System.out.println("第" + lineNumber + "行: " + fields);
            lineScanner.close();
        }

    } catch (FileNotFoundException e) {
        System.err.println("CSV文件未找到: " + e.getMessage());
    }
}

对于大文件和高性能场景，传统IO可能不够用。NIO和内存映射提供了更高效的解决方案。

🎯 NIO vs 传统IO对比

import java.nio.channels.*;
import java.nio.ByteBuffer;

public class NIOComparison {

    // 传统IO方式
    public static void traditionalCopy(String source, String target) {
        long startTime = System.nanoTime();

        try (FileInputStream fis = new FileInputStream(source);
             FileOutputStream fos = new FileOutputStream(target)) {

            byte[] buffer = new byte[8192];
            int bytesRead;

            while ((bytesRead = fis.read(buffer)) != -1) {
                fos.write(buffer, 0, bytesRead);
            }

        } catch (IOException e) {
            e.printStackTrace();
        }

        long endTime = System.nanoTime();
        System.out.printf("传统IO耗时: %.2f ms%n", (endTime - startTime) / 1_000_000.0);
    }

    // NIO方式
    public static void nioCopy(String source, String target) {
        long startTime = System.nanoTime();

        try (FileChannel sourceChannel = FileChannel.open(Paths.get(source), StandardOpenOption.READ);
             FileChannel targetChannel = FileChannel.open(Paths.get(target),
                     StandardOpenOption.CREATE, StandardOpenOption.WRITE)) {

            ByteBuffer buffer = ByteBuffer.allocateDirect(8192); // 直接缓冲区

            while (sourceChannel.read(buffer) != -1) {
                buffer.flip(); // 切换到读模式
                targetChannel.write(buffer);
                buffer.clear(); // 清空缓冲区，准备写入
            }

        } catch (IOException e) {
            e.printStackTrace();
        }

        long endTime = System.nanoTime();
        System.out.printf("NIO耗时: %.2f ms%n", (endTime - startTime) / 1_000_000.0);
    }
}

public class MemoryMappedFile {

    public static void memoryMappedCopy(String source, String target) {
        long startTime = System.nanoTime();

        try (RandomAccessFile sourceFile = new RandomAccessFile(source, "r");
             RandomAccessFile targetFile = new RandomAccessFile(target, "rw");
             FileChannel sourceChannel = sourceFile.getChannel();
             FileChannel targetChannel = targetFile.getChannel()) {

            long fileSize = sourceChannel.size();

            // 内存映射源文件
            MappedByteBuffer sourceBuffer = sourceChannel.map(
                FileChannel.MapMode.READ_ONLY, 0, fileSize);

            // 内存映射目标文件
            MappedByteBuffer targetBuffer = targetChannel.map(
                FileChannel.MapMode.READ_WRITE, 0, fileSize);

            // 直接内存复制
            targetBuffer.put(sourceBuffer);

        } catch (IOException e) {
            e.printStackTrace();
        }

        long endTime = System.nanoTime();
        System.out.printf("内存映射耗时: %.2f ms%n", (endTime - startTime) / 1_000_000.0);
    }

    // 大文件处理
    public static void processLargeFile(String filePath, long chunkSize) {
        try (RandomAccessFile file = new RandomAccessFile(filePath, "r");
             FileChannel channel = file.getChannel()) {

            long fileSize = channel.size();
            long position = 0;

            while (position < fileSize) {
                long remaining = fileSize - position;
                long currentChunk = Math.min(chunkSize, remaining);

                MappedByteBuffer buffer = channel.map(
                    FileChannel.MapMode.READ_ONLY, position, currentChunk);

                // 处理当前块
                processBuffer(buffer);

                position += currentChunk;

                // 释放内存映射（帮助垃圾回收）
                Cleaner cleaner = ((DirectBuffer) buffer).cleaner();
                if (cleaner != null) {
                    cleaner.clean();
                }
            }

        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}

// 文件复制工具框架
public class FileCopier {
    private final int bufferSize;
    private final boolean showProgress;

    public FileCopier(int bufferSize, boolean showProgress) {
        this.bufferSize = bufferSize;
        this.showProgress = showProgress;
    }

    public void copy(String source, String target) throws IOException {
        try (FileInputStream fis = new FileInputStream(source);
             FileOutputStream fos = new FileOutputStream(target);
             BufferedInputStream bis = new BufferedInputStream(fis, bufferSize);
             BufferedOutputStream bos = new BufferedOutputStream(fos, bufferSize)) {

            long fileSize = new File(source).length();
            long totalBytes = 0;
            byte[] buffer = new byte[8192];
            int bytesRead;

            long startTime = System.currentTimeMillis();

            while ((bytesRead = bis.read(buffer)) != -1) {
                bos.write(buffer, 0, bytesRead);
                totalBytes += bytesRead;

                if (showProgress) {
                    showProgress(totalBytes, fileSize, startTime);
                }
            }
        }
    }

    private void showProgress(long current, long total, long startTime) {
        double percent = (double) current / total * 100;
        long elapsed = System.currentTimeMillis() - startTime;
        double speed = current / (elapsed / 1000.0) / (1024 * 1024); // MB/s

        System.out.printf("\r进度: %.1f%% 速度: %.2f MB/s", percent, speed);
    }
}

public class TextAnalyzer {
    private final Map wordFrequency = new HashMap<>();
    private int charCount = 0;
    private int wordCount = 0;
    private int lineCount = 0;

    public void analyze(String filePath) throws IOException {
        try (BufferedReader reader = new BufferedReader(new FileReader(filePath))) {
            String line;
            while ((line = reader.readLine()) != null) {
                lineCount++;
                charCount += line.length();

                // 简单的单词分割
                String[] words = line.split("\\s+");
                for (String word : words) {
                    if (!word.isEmpty()) {
                        wordCount++;
                        wordFrequency.merge(word.toLowerCase(), 1, Integer::sum);
                    }
                }
            }
        }
    }

    public void printStatistics() {
        System.out.println("字符数: " + charCount);
        System.out.println("单词数: " + wordCount);
        System.out.println("行数: " + lineCount);

        System.out.println("\n词频TOP10:");
        wordFrequency.entrySet().stream()
            .sorted(Map.Entry.comparingByValue().reversed())
            .limit(10)
            .forEach(entry -> System.out.printf("%s: %d%n",
                      entry.getKey(), entry.getValue()));
    }
