如何构造 Stream

Stream 可以通过多种数据源创建，最常用的是从集合（Collection）创建。

  • 1. 从集合 (Collection) - 最常用的方式 
    List<String> list = List.of("Java", "Python", "Go");
Stream<String> stream = list.stream();
  • 2. 从数组 (Array) 
    String[] arr = {"Java", "Python", "Go"};
Stream<String> stream = Arrays.stream(arr);
  • 3. 直接通过值 (Stream.of) 
    Stream<String> stream = Stream.of("Java", "Python", "Go");
  • 4. 构造无限流 (Infinite Streams) 
    Stream<Double> randoms = Stream.generate(Math::random).limit(5);
Stream<Integer> evens = Stream.iterate(0, n -> n + 2).limit(10);

* 深入理解无限流

无限流是 Stream API 的一大特色，允许定义无穷的数据源，只有在需要时才计算（延迟执行）。

1. Stream.generate(Supplier<T> s)

机制： 基于 Supplier 接口（无参，有返回值），单纯地"生产"数据，不依赖上一次生成的结果。

适用场景： 生成随机数、常量流、UUID 等无规律数据。

// 示例：生成 3 个随机 UUID
// UUID::randomUUID 符合 Supplier<UUID> 签名
Stream.generate(java.util.UUID::randomUUID)
      .limit(3)
      .forEach(System.out::println);
// 输出示例: e58ed763-928c-4155-bee9-fdbaaadc15f3 ...

2. Stream.iterate(T seed, UnaryOperator<T> f)

机制： 这是一个迭代过程。从种子值 seed 开始，将函数 f 反复应用（seed, f(seed), f(f(seed))...）。

适用场景： 生成等差/等比数列、时间序列、斐波那契数列等有规律数据。

// 示例：生成倍数序列 (1, 2, 4, 8, 16...)
// n -> n * 2 符合 UnaryOperator<Integer> 签名 (输入=输出)
Stream.iterate(1, n -> n * 2)
      .limit(5)
      .forEach(System.out::println);
// 过程: 1 -> 2 -> 4 -> 8 -> 16
⚠️ 警告： 无限流必须配合 limit() 或其他短路操作（Short-circuiting）使用，否则一旦执行终端操作（如 forEach），程序将陷入死循环！

[T] 遍历:forEach()

📋 方法签名

void forEach(Consumer<? super T> action)
参数说明：
  • Consumer<? super T> action - 对流中每个元素执行的操作，是一个消费型函数式接口
返回值：

void - 无返回值，这是一个终端操作

💡 使用提示：

forEach是终端操作，调用后Stream结束。适合遍历处理，但不能改变Stream中的元素。在并行Stream中要注意线程安全问题。

forEach() 用于遍历Stream中的每个元素，是Stream中最基本的操作。

🔴 传统写法的痛点：

// 传统的for-each循环
for (Student student : students) {
    System.out.println("学生姓名: " + student.getName());
    System.out.println("学生年龄: " + student.getAge());
}

// 传统for循环（需要处理索引）
for (int i = 0; i < students.size(); i++) {
    Student student = students.get(i);
    System.out.println("第" + (i + 1) + "个学生: " + student.getName());
}

🟢 Stream forEach() 解决方案：

// 简洁的forEach
students.stream()
    .forEach(student -> {
        System.out.println("学生姓名: " + student.getName());
        System.out.println("学生年龄: " + student.getAge());
    });

// 使用方法引用（更简洁）
students.stream()
    .forEach(System.out::println);

// 带索引的遍历（需要额外处理）
AtomicInteger index = new AtomicInteger(0);
students.stream()
    .forEach(student -> {
        System.out.println("第" + (index.incrementAndGet()) + "个学生: " + student.getName());
    });

💡 使用场景和注意事项：

  • 遍历处理：需要对每个元素执行相同操作时
  • 终端操作：forEach是终端操作，调用后Stream结束
  • 无返回值：不能在forEach中返回结果，适合副作用操作
  • 并行安全：在并行Stream中要注意线程安全问题

forEach() 让遍历操作更加简洁，但要注意它是终端操作且不能改变Stream中的元素！

筛选:filter()

📋 方法签名

Stream<T> filter(Predicate<? super T> predicate)
参数说明：
  • Predicate<? super T> predicate - 断言型函数式接口，返回true表示保留元素，false表示过滤掉
返回值：

Stream<T> - 包含所有满足predicate条件的元素的新Stream

💡 使用提示：

filter是中间操作，是惰性求值的。可以链式调用多个filter来组合复杂的筛选条件。通常将筛选操作放在链式调用的前面以减少处理的数据量。

筛选操作用于根据条件过滤元素，是Stream中最常用的操作之一。

🔍 filter() - 条件过滤

// 传统写法 - 繁琐
List<Student> adults = new ArrayList<>();
for (Student s : students) {
    if (s.getAge() >= 18) {
        adults.add(s);
    }
}

// Stream写法 - 简洁
List<Student> adults = students.stream()
    .filter(student -> student.getAge() >= 18)
    .collect(Collectors.toList());

// 复杂条件筛选
List<Student> qualifiedStudents = students.stream()
    .filter(s -> s.getAge() >= 18 && s.getScore() > 80 && s.isActive())
    .collect(Collectors.toList());

// 多次filter链式调用（可读性更好）
List<Student> result = students.stream()
    .filter(s -> s.getAge() >= 18)           // 年龄筛选
    .filter(s -> s.getScore() > 80)          // 成绩筛选
    .filter(Student::isActive)                 // 状态筛选
    .collect(Collectors.toList());

筛选操作用于根据条件过滤元素，是Stream中最常用的操作之一。

// 传统写法 - 需要Set辅助
Set<String> uniqueNames = new HashSet<>();
List<String> uniqueNameList = new ArrayList<>();
for (Student s : students) {

List<String> uniqueNames = students.stream()

* 筛选:take/dropWhile()

📋 方法签名

Stream<T> takeWhile(Predicate<? super T> predicate) Stream<T> dropWhile(Predicate<? super T> predicate)
参数说明：
  • Predicate<? super T> predicate - 断言条件，用于判断是否继续处理元素
返回值：

Stream<T> - 返回截取后的新Stream

💡 使用提示：

takeWhile()取元素直到遇到第一个不满足条件的元素；dropWhile()跳过元素直到遇到第一个不满足条件的元素。这两个都是短路操作，可以提升性能。注意：对于无序流，行为可能不确定。

takeWhile() 和 dropWhile() 是 Java 9 新增的短路操作，用于按条件截取数据流。

✂️ takeWhile() - 满足条件时取元素

// 传统写法 - 需要手动控制循环
List<Integer> result = new ArrayList<>();
for (Integer num : numbers) {
    if (num < 4) {
        result.add(num);
    } else {
        break;  // 遇到不满足的条件就停止
    }
}

// Stream写法 - 简洁的短路操作
List<Integer> numbers = List.of(1, 2, 3, 4, 5, 1, 2);
List<Integer> result = numbers.stream()
    .takeWhile(n -> n < 4)  // 取直到遇到不满足条件的元素
    .collect(Collectors.toList());
// 结果: [1, 2, 3]  (遇到4就停止，不会继续取后面的1,2)

🗑️ dropWhile() - 丢弃满足条件的元素

// 传统写法 - 需要标志位控制
List<Integer> result = new ArrayList<>();
boolean startTaking = false;
for (Integer num : numbers) {
    if (!startTaking && num >= 4) {
        startTaking = true;
    }
    if (startTaking) {
        result.add(num);
    }
}

// Stream写法 - 优雅的短路操作
List<Integer> result2 = numbers.stream()
    .dropWhile(n -> n < 4)  // 丢弃直到遇到不满足条件的元素
    .collect(Collectors.toList());
// 结果: [4, 5, 1, 2]  (从4开始取，包括后面的所有元素)

💡 实际应用场景：

// 场景1：处理排序后的数据，取连续满足条件的部分
List<Student> students = getStudentsByScore();  // 已按成绩排序
List<Student> topStudents = students.stream()
    .takeWhile(s -> s.getScore() >= 90)  // 取连续90分以上的学生
    .collect(Collectors.toList());

// 场景2：跳过日志文件的头部信息
List<String> dataLines = Files.lines(logFile)
    .dropWhile(line -> line.startsWith("#"))  // 跳过注释行
    .collect(Collectors.toList());

// 场景3：处理时间序列数据
List<Double> temperatures = getTemperatureReadings();
List<Double> normalTemp = temperatures.stream()
    .takeWhile(t -> t >= 36.0 && t <= 37.5)  // 取正常体温数据
    .collect(Collectors.toList());
⚠️ 注意事项：
  • 这是 Java 9+ 的特性，需要 Java 9 或更高版本
  • 与 filter() 不同：filter() 处理所有元素，而 takeWhile/dropWhile() 是短路操作
  • 对于 有序流，行为是确定的；对于 无序流，结果可能不同

takeWhile() 和 dropWhile() 提供了强大的条件截取能力，特别适合处理有序数据和需要短路操作的场景！

映射:map()

📋 方法签名

<R> Stream<R> map(Function<? super T, ? extends R> mapper)
参数说明：
  • Function<? super T, ? extends R> mapper - 函数式接口，将类型为T的元素转换为类型为R的元素
返回值：

Stream<R> - 包含转换后元素的新Stream，元素类型可能不同

💡 使用提示：

map是中间操作，可以改变Stream中元素的类型。常用于数据转换、对象属性提取、格式转换等场景。map操作是一对一的映射，每个输入元素只产生一个输出元素。

映射操作用于转换Stream中的元素类型或结构，是Stream API的核心功能。

🔄 map() - 类型转换

// 传统写法 - 需要显式循环
List<String> names = new ArrayList<>();
for (Student student : students) {
    names.add(student.getName());
}

// Stream写法 - 简洁
List<String> names = students.stream()
    .map(Student::getName)
    .collect(Collectors.toList());

// 复杂转换
List<StudentDTO> dtos = students.stream()
    .map(student -> {
        StudentDTO dto = new StudentDTO();
        dto.setName(student.getName());
        dto.setAge(student.getAge());
        return dto;
    })
    .collect(Collectors.toList());

// 多步转换
List<Integer> nameLengths = students.stream()
    .map(Student::getName)        // Student -> String
    .map(String::length)         // String -> Integer
    .collect(Collectors.toList());

🔢 基本类型映射：

// 基本类型映射 - 避免自动装箱
IntStream ages = students.stream()
    .mapToInt(Student::getAge);

DoubleStream scores = students.stream()
    .mapToDouble(Student::getScore);

LongStream ids = students.stream()
    .mapToLong(Student::getId);

// 基本类型Stream的优势
double averageAge = students.stream()
    .mapToInt(Student::getAge)
    .average()
    .orElse(0.0);  // 无需Optional处理

映射操作是Stream的核心，map()用于一对一转换，flatMap()用于一对多扁平化！

映射:flatMap()

📋 方法签名

<R> Stream<R> flatMap(Function<? super T, ? extends Stream<? extends R>> mapper)
参数说明：
  • Function<? super T, ? extends Stream<? extends R>> mapper - 将每个元素映射为一个Stream的函数式接口
返回值：

Stream<R> - 扁平化后的新Stream，包含所有子Stream的元素

💡 使用提示：

flatMap是中间操作，实现一对多映射。常用于处理嵌套集合、数组展开、对象扁平化等场景。flatMap会自动将多个Stream合并为一个Stream。

映射操作用于转换Stream中的元素类型或结构，是Stream API的核心功能。

📦 flatMap() - 扁平化映射

// 场景：学生选课列表，获取所有课程名称
List<Student> students = getStudents();

// 传统写法 - 嵌套循环
List<String> allCourses = new ArrayList<>();
for (Student student : students) {
    for (Course course : student.getCourses()) {
        allCourses.add(course.getName());
    }
}

// Stream写法 - 使用flatMap扁平化
List<String> allCourses = students.stream()
    .flatMap(student -> student.getCourses().stream())  // 将List<Course>扁平化为Stream<Course>
    .map(Course::getName)
    .distinct()
    .collect(Collectors.toList());

// 字符串分割并扁平化
List<String> words = Arrays.asList("hello world", "java stream", "functional programming")
    .stream()
    .flatMap(sentence -> Arrays.stream(sentence.split(" ")))
    .distinct()
    .collect(Collectors.toList());
// 结果: ["hello", "world", "java", "stream", "functional", "programming"]

映射操作是Stream的核心，map()用于一对一转换，flatMap()用于一对多扁平化！

调试:peek()

📋 方法签名

Stream<T> peek(Consumer<? super T> action)
参数说明：
  • Consumer<? super T> action - 对Stream中每个元素执行的操作，通常用于调试
返回值：

Stream<T> - 原始Stream，peek操作不会修改Stream内容

💡 使用提示：

peek是中间操作，主要用于调试和监控。可以在Stream处理链中插入查看点，但不应修改元素状态。适合配合日志输出或断点调试使用。

peek() 是一个中间操作，主要用于调试Stream处理过程，让我们能够查看每个处理阶段的数据。

🔍 peek() - 调试Stream处理

// 传统调试方式 - 需要打断点或打印变量
List<String> names = new ArrayList<>();
for (Student student : students) {
    if (student.getAge() >= 18) {
        System.out.println("过滤后的学生: " + student.getName());  // 调试输出
        names.add(student.getName());
    }
}

// Stream使用peek()调试 - 链式调试
List<String> result = students.stream()
    .filter(student -> student.getAge() >= 18)
    .peek(student -> System.out.println("过滤后: " + student.getName()))
    .map(Student::getName)
    .peek(name -> System.out.println("映射后: " + name))
    .filter(name -> name.length() > 2)
    .collect(Collectors.toList());

🛠️ peek() 的多种调试用途

// 用途1：跟踪数据转换过程
List<Integer> squares = numbers.stream()
    .peek(n -> System.out.println("原始: " + n))
    .map(n -> n * n)
    .peek(n -> System.out.println("平方: " + n))
    .filter(n -> n > 50)
    .peek(n -> System.out.println("过滤后: " + n))
    .collect(Collectors.toList());

// 用途2：验证数据流内容
Set<String> categories = products.stream()

        }
    })
    .filter(p -> p.getCategory() != null)

// 用途3：收集统计信息（副作用）
AtomicInteger count = new AtomicInteger(0);
List<Student> processed = students.stream()
    .peek(student -> count.incrementAndGet())
    .filter(Student::isActive)
    .collect(Collectors.toList());

Optional<T>/T/U - 规约结果：无初始值时返回Optional，有初始值时返回具体类型

💡 使用提示：

reduce是最灵活的终端操作，可用于求和、求积、字符串拼接等任意聚合操作。有初始值的版本更安全。在并行Stream中，combiner函数用于合并各线程的局部结果。

reduce() 操作用于将Stream中的元素按照指定的规则"规约"成一个值，是最灵活的聚合操作。

📋 方法签名

参数说明：
  • Stream<? extends T> a - 第一个要合并的Stream
  • Stream<? extends T> b - 第二个要合并的Stream

);

        undergraduates.stream(),
        graduateStudents.stream(),

    )
    .flatMap(Function.identity());  // 扁平化合并

并行优化:unordered()

📋 方法签名

参数说明：
  • 无参数 - 移除Stream的有序约束，允许并行处理时不保持原始顺序
返回值：

💡 使用提示：

unordered() 是一个中间操作，用于移除Stream的有序约束，在并行处理中可以显著提升性能。

🚀 unordered() - 移除有序约束

    .collect(Collectors.toList());
// 结果顺序可能不同，但并行效率更高

// 数据库查询的Stream包装
public Stream<Product> getProductsStream(String category) {
    Connection conn = getConnection();
    PreparedStatement stmt = null;
    ResultSet rs = null;

    try {
        stmt = conn.prepareStatement("SELECT * FROM products WHERE category = ?");
        stmt.setString(1, category);
        rs = stmt.executeQuery();

        return StreamSupport.stream(
            new Spliterators.AbstractSpliterator<Product>(Long.MAX_VALUE, 0) {
                @Override
                public boolean tryAdvance(Consumer<? super Product> action) {
                    try {
                        if (rs.next()) {
                            action.accept(mapRowToProduct(rs));
                            return true;
                        }
                        return false;
                    } catch (SQLException e) {
                        throw new RuntimeException(e);
                    }
                }
            }, false)
        .onClose(() -> {
            // 确保资源被正确关闭
            try {
                if (rs != null) rs.close();
                if (stmt != null) stmt.close();
                if (conn != null) conn.close();
                System.out.println("数据库资源已释放");
            } catch (SQLException e) {
                System.err.println("关闭数据库资源时出错: " + e.getMessage());
            }
        });

    } catch (SQLException e) {
        // 如果创建Stream失败，需要手动关闭资源
        closeQuietly(rs, stmt, conn);
        throw new RuntimeException(e);
    }
}

public List<StudentCourseSummary> generateCourseSummary(List<Student> students) {

        .filter(Student::isActive)                                    // 筛选活跃学生
        .flatMap(student -> student.getCourses().stream()               // 扁平化课程列表
            .map(course -> new StudentCourseInfo(student, course)))     // 组合学生和课程信息
        .collect(Collectors.groupingBy(                                // 按课程分组

            Collectors.collectingAndThen(
                Collectors.toList(),
                courseInfos -> {
                    double averageScore = courseInfos.stream()
                        .mapToDouble(StudentCourseInfo::getScore)
                        .average()
                        .orElse(0.0);

                    long passCount = courseInfos.stream()
                        .mapToLong(info -> info.getScore() >= 60 ? 1 : 0)
                        .sum();

                    return new StudentCourseSummary(
                        courseInfos.get(0).getCourseName(),
                        courseInfos.size(),
                        averageScore,
                        (double) passCount / courseInfos.size() * 100
                    );
                }
            )
        ))
        .values()
        .stream()
        .sorted(Comparator.comparing(StudentCourseSummary::getAverageScore).reversed())
        .collect(Collectors.toList());

// 1. 避免修改Stream中的元素

    .peek(student -> student.setScore(student.getScore() + 10))  // 副作用！
    .collect(Collectors.toList());

// 正确：在map中创建新对象
List<Student> result = students.stream()
    .map(student -> {
        Student newStudent = new Student(student);
        newStudent.setScore(student.getScore() + 10);
        return newStudent;
    })
    .collect(Collectors.toList());

// 正确：一次性计算
IntSummaryStatistics stats = students.stream()
